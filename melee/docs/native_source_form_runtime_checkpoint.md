# Direct alternate source runtime checkpoint

> Dated evidence, not the current backlog. Results and limitations below apply
> to the recorded build. See the
> [evidence index](checkpoint_index.md) before treating an old pending item as new work.

Alternate families now prepare two independent source packages and require each
member's zero-argument `form_activated` event. Both immutable banks, imported
tables and leases are checked before either member publishes; both then enter
the actual Player alternate mapping. Candidate relocation rebinds both plain
member descriptors without moving package owners. Direct load checks both kinds
and unwinds all acquired leases on failure. Companion activation remains
explicitly unsupported until follower CPU/history contracts are connected.

`nativeFighterRuntime_AlternatePair` verifies immutable membership in one active
alternate family. Player active/dormant role permutation is a separate check.
The destination actor must be live and outside a running invocation before its
native generation and VM binding can reset; a running source is expected.
`form_activated` is prepared and executed through the actual Fighter hook table.

The substantive common transfer moved from `ftcommon.c` to `ftformtransfer.c`,
with the same exported routine and no forwarding wrapper. Its source branch
checks exact package, selected bank/program, imported data, actor storage/schema,
generation and status. It dispatches the destination's own code ID directly,
without a stock-special handler or authored native finish thunk. Retained source
Items also require their exact program/storage identity at continuation barriers.
Original unscripted stock finish callers retain their stock finish contract.

The generic `forms.activate_partner()` binding returns `Void` only after the
framework completes and the source's identity/layout remains valid. Rejection
or late failure is not authored success; ordinary dormancy preserves source
storage and allows its callback to return. Late native mutations are not
automatically undone. No allocation or source parsing occurs during transfer.
