# Interpreted colors and held-item observations

> Dated evidence, not the current backlog. Results and limitations below apply
> to the recorded build. See the
> [evidence index](checkpoint_index.md) before treating an old pending item as new work.

The ordinary interpreter now reads the current costume index and the common
base model scale independently from per-instance scale. It packs RGBA using
integer bytes and writes Fighter/Article presentation fields directly. Native
diffuse traversals preserve their distinct instance-joint rules. Outline lookup
installation uses the source package's declared visibility table and the current
costume's actual draw-object ordinals. Layer admission uses the Article's own
imported metadata; missing data leaves layering disabled rather than fabricating
a successful binding.

Held and auxiliary queries use current native slots and retain full integer
creation IDs, including foreign held items. Visibility and pause use the common
Item operations. Drop notification preserves the common native sequence while
retaining the Fighter's physical identity, payload, program and storage across
callbacks. These operations do not turn foreign items into originally created
or controllably attached Articles.

See [colors and presentation](scripting/colors.md) and
[Fighter item controls](scripting/held_item_controls.md) for authored names,
return values and absence behavior. Fixtures that omit these engine families
explicitly reject their runtime leaves; they do not supply successful fake
implementations.

## Integration and remaining scope

The native client, content tool and separate test-only C reference exporter
build. The selected 38 interpreter/content/pool/lifecycle/allocator CTests pass. Actual
copied-draft preparation progresses to later operations; the exact first
failures and receipt are in the [roster census](native_source_roster_admission_census.md).
That census does not establish complete fighter activation or gameplay.

The connected color fixture at
`A:/FreakMelee-test-archives/script-colors-final/receipt.json` passes 157 checks
across eleven cases and three native comparisons. It executes actual compiler,
Fighter/Item actors, VM, catalog and property routing with controlled asset
metadata and constructed primary graphs. Native material traversal, owned
outline lookup and model-layer validation bodies are extracted unchanged from
production sources. The fixture covers palette helper decisions, full-width
integer packing, an out-of-range wide visibility slot, native no-op writes,
foreign parameter-storage rejection and compile-time type/access negatives.
It does not prove retail Game & Watch activation, a GPU frame or material
callback reentry; those traversals contain no authored callback invocation.

The connected held-item fixture at
`A:/FreakMelee-test-archives/script-fighter-item-query-presentation-final/receipt.json`
passes 408 checks across 47 cases, with fourteen native comparisons and 38 source
calls. Compiler, actor publication, VM, current native slot queries and the
common visibility/pause/drop bodies execute directly. The comparisons include
ten scale cases and four visibility/pause cases. Drop notification invokes an
interpreted hook; its surrounding notification/statistics leaves are controlled.
The fixture includes noncanonical Bool rejection and continuation failures from
caller retirement, new life, item retirement and callback failure. Native peers
are explicitly restored for actor snapshot tests; complete match snapshots and
stock pickup/drop integration are not established by this fixture.

This checkpoint predates the connected target-controller colors, taunt entry,
common pickup policies and explicit initial-collision factory flag. Their
subsequent acceptance is recorded in the
[common policy checkpoint](native_source_common_policy_checkpoint.md). Secondary models
and owned resource collections still need real allocation/animation/destruction
and rollback ownership. The HSD reservation work is a separate prerequisite;
an allocation-demand census is not permission to load an uncovered graph.

No game, installed collection, original ISO or user draft was changed. All
progress remains local and the full project goal remains unfinished.
