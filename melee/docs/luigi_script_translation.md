# Luigi script closure

Status: baseline14's actual generated versus candidate passes 4,918 source comparisons after removal of obsolete raw metadata reinterpretation paths, plus two targeted gameplay pairs. Cyclone effect ownership and wider gameplay acceptance remain pending; this is not whole-fighter independence acceptance.

The existing template owns 18 special states (341–358), Green Missile phases, Fireball article behavior, held-item presentation, attributes and lifecycle callbacks. The clone base retains stock behavior for untouched plain clones; the generated template requests `behavior independent`. It now supplies an explicit 51-role semantic bone map from the supplied v1.02 common asset, with 61 physical joints and no omissions. Fireball occupies item slot0, the import article mask is1, effect bank18 and sound bank17. Four standard result/intro/ending/wait archive roots remain owned metadata.

The CPU candidate callback reproduces Luigi's single 60-unit ranged geometry probe followed by command38 insertion. The probe still runs when the shared eight-entry list is full; shared candidate52 remains before this callback. Ground/air and forced-fall status do not introduce extra Luigi gates. Recovery queues vertical stick0, destination-directed horizontal stick127, one frame of B, B release, a 40-frame wait and explicit completion. These operations draw no RNG.

The falling-destination predicate runs after the common forced-fall, grounded, rising and wall-contact gates in `ftCo_800A3498`. Luigi returns whether the actual position delta is negative; a zero delta does not use the ordinary destination-above-ECB comparison. This is distinct from the existing falling-recovery size predicate.

The damaging common taunt requires action metadata group99, category2, animation flags4 and statistics flags0 when incoming canonical move byte113 is selected. The source canonical word convention is independent of native memory byte order. Previously, native code reinterpreted the console word as `Struct2070`, bypassing the Luigi low-byte113 branch and interpreting its replacement word incorrectly. Native common metadata now decodes each semantic field explicitly, and the script uses a generic integer metadata builder. The original incoming group controls the attack-counter decision before the authored query; the shared heavy-item rewrite and statistics setup remain afterward. This is an intentional correction to malformed native baseline behavior, not an exact match to that bug. The source fixture must compare independently decoded console semantics and actual generated callbacks, and must retain any differences in evidence.

Cyclone charge is initialized false on load/death. The stock reads an incompletely initialized charge field; the template deliberately uses deterministic owned state. This existing decision remains unchanged.

Video-only demo modes9/10 remain outside versus closure. Stock uses an extra RunBrake/Kneebend animation table, maps those modes to clips14/15, and looks up `ftDemoVi0102MotionFileLuigi` / `ftDemoVi1101MotionFileLuigi` through inherited selectors. An independent module clears those selectors; no whole video-demo parity is claimed. Ordinary versus specials/taunt and the four standard demo-root names are separate from that deferred facility.

Source preparation is saved in `.local/luigi-independence-source/{original_sources.inc,source_manifest.json,rig.json,rig_definition.inc}`. The original bodies come from frozen baseline11, before the new destination/metadata routing. The fixture loads the actual final generated full module, imported parameters, matching SDK and real lifetime predicate. It compares candidate order/capacity and exact query arguments, controller command bytes, common-gate placement, semantic action metadata and attack-counter ordering. Removed/recycled callback-source cases stop before cached metadata continuation. Gameplay tests require a coordinated frozen snapshot and remain hidden, muted, accelerated and drawn.

`tests/native/luigi_policy_stock_compare.py` loads the full generated module recompiled against frozen baseline14, verifies its ABI fingerprint and uploads its actual imported parameter table. Final matching evidence is saved in `.local/luigi-independence-source/baseline14-fixture/{build.log,result.log,result.json}`; the project and normal clone/import/script-build logs are alongside it under `baseline14-project` and `baseline14-*.log`. The unchanged 4,918 cases comprise 144 ranged decisions, two recovery sequences, 48 full common destination-gate comparisons, 4,096 independently decoded console metadata/counter/heavy/status comparisons, 625 generated integer-builder mask checks, two removed/recycled source checks, and one explicit old-malformed-native versus intended taunt case. The old native representation difference is retained and checked separately rather than normalized away. Baseline12's compiler return-lowering failure is preserved as diagnostic evidence. Baseline13 passed the same source suite before cleanup; baseline14's normal clone/import/script-build workflow and repeated suite both pass with unconditional semantic decoding and no obsolete raw reinterpretation branches. No gameplay was launched for this source acceptance.

Two targeted hidden, muted, accelerated matches with drawing compare stock and independent Luigi: common taunt and active level-9 CPU, totaling 2,240 controller samples. The CPU case rejects idle input and compares 137 action transitions and 15 damage events. These traces cover fighter/item state and RNG, not Cyclone model visibility or slope alignment. Evidence is saved in `.local/luigi-metadata-runtime14/{results.json,taunt-result.log,cpu-result.log}`. The final Release build and thirteen focused callback, lifetime, event and parameter checks pass.

The remaining concrete effect boundary is effect0x509: `efLib_Cb_ftLg_SpecialLw` reads the stock common-motion union's collision word, while the script keeps `cyclone_collision` in its own state. The current native effect callback can therefore miss slope alignment even though fighter physics is authored. Effect behavior needs a generic owned lifecycle solution and its own source/runtime comparisons before closure.
