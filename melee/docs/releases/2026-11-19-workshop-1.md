## Workshop

- Create and edit fighters with a coding agent from the installed game folder. The included Workshop tool works over MCP or the command line, with offline documentation and examples. Agents can edit drafts and live Workshop sessions, validate scripts, build and install fighters, and run practice tests with traces and screenshots. Start with `START_HERE.md` beside the game.
- The Action Editor now supports capsule hitboxes, fractional hit and throw damage, and hitboxes that launch opponents toward a point or pull them along with a moving attack. Choose whether a hitbox can hit the fighter you are holding.
- Fighter packages can include their own sound banks and animated effects. Use custom sounds in timeline events and scripts, and customize entrances, victory music, and directional taunts.
- Exiting a Workshop practice test with the standard match-exit shortcut returns you to the draft preview.

## Online and practice

- Send fighters to friends from the Workshop while they are offline. They can install the fighter from their Inbox. Successful installs clear the gift, and unclaimed gifts expire after seven days.
- Set a lobby password, a name, and a limit of two, three, or four active fighters. The lobby list shows which rooms are locked and how many people are fighting, waiting, or spectating.
- Change lobby settings and fighter rotation from the match rules. The rules and item switch use the original Melee menu artwork and item controls.
- See the fighter or outfit and download progress while receiving a lobby gift or syncing match content.
- Choose a stage for local practice. The Training Room tile uses the stock stage-select artwork and animation.

## Controls and feedback

- Control profile assignments persist per controller port. The calibration review shows raw and calibrated stick positions together.
- Hold the D-pad or use the C-stick to scroll News. The F2 feedback controls fade when you point at them so you can see the screenshot underneath. Workshop agents can also prepare bug reports and feature requests for submission through the feedback system.
