contract table. The original 28 hooks retain their ABI; 25 added CPU hooks make

are checked against the independently audited event descriptors. Names resolve

fighter-kind/donor policy for source actors. Generic defaults remain: initial

authored fallthrough or successful Bool false. Stick outputs stage together.

generation, userdata/class/kind/data, source program/storage and logical status.

callbacks. Old duplicated guard paths were consolidated; genuine non-source

wrapper or stock authored fallback is added for interpreted sources.

The apparent early-constructor issue was disproved by the actual call graph:
CPU initialization is in reset/death, called after Attach/Load. That lifecycle
was preserved rather than rebinding actors or replaying initialization late.

access rules, including legitimate null indexed slots and unindexed missing-child
behavior. A bounded default JObj topology simulation follows native instance
resolution and duplicate descriptor-ID insertion instead of counting raw records.

stack, with an explicit 65536-state capacity limit. Failed admission publishes
neither an early valid script prefix nor rewritten destination pointers.

loader through an explicit GrStageImportOptions field. Green Greens' effect
command requires this geometry; no ownerless stage exemption or guessed bounds.
