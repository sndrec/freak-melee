# Direct source Article resources: Chain audit

The smallest coherent next slice is source-prepared named model roots plus an Article-owned collision/model collection, direct typed resource selectors, and real collection retirement. Accepting `resources capacity 30` and `model_root` metadata alone would leave Chain unusable: the current resource runtime requires a native behavior Definition and C ItemLogic identity, and the direct catalog has no resource operations.

This audit changes no production, template, project, CLI or plan files. It does not establish full Sheik compilation, gameplay, rendering or rollback acceptance.

## What is already owned

`nativeSourceAssets_Import` consumes the package's owned facts/DATs. Sheik's copied layout selects `FtCharacterItems_Chain`; `ftCharacterAssets.c::import_seak_chain_attributes` imports numeric fields through byte `0x63`, then imports pointer slots `0x64` and `0x68` as `DAT_JOINT`. It validates the native link count within 2..30. The graphs are already in the character's pinned import arena; they are not donor-global graphs missing from the source package.

The fresh isolated actual-library probe passed **12 checks**: [receipt](A:/FreakMelee-test-archives/article-resource-owned-import-review3/receipt.json). It reads original v1.02 `PlSk.dat` (SHA256 `b75ee373521c4deb97ea8863e4d07e37b589dc7756c9e375e750e2043075ce89`) and imports owned character/Articles through `ftCharacterAssets_Import` with the Chain layout. The Article is slot 3. Its original special-attribute source is `0x3C1C`, and original link count is **20**.

Both pointer slots resolve to **the same original graph at `0x11EC8`**. Calling the existing `itArticle_ImportModelRoots` with names Link/Tip and offsets 100/104 publishes two names whose roots equal the already-owned typed attribute pointers. Import-cache alias identity is retained. Distinct names must not require distinct descriptor addresses. Each live link/tip still needs a separate mutable JObj instance.

The probe's first version incorrectly required different descriptor pointers; that failed assertion is retained in the earlier private archive. The passing probe checks the actual shared-graph contract. No Item/resource construction, model instance, game or global build was run.

| `it_802BCB88`, `itlinkhookshot.c::it_802A6DC8` | Translate model nodes, update creator hitbox endpoints in the native stride/order, normalize direction and cross-product basis, copy matrix, set flags, then scale only its 3×3 columns by link length. Preserve twelve matrix cells and native arithmetic order; do not replace them with an Euler/SRT approximation. |
| `itseakchain.c::inlineA0`, `it_802BB20C`, interaction callback | Notify owner, clear mutable owner/retained parent, free the collection, then remove Item. Parent lifetime differs from mutable Item owner; owner reassignment must not silently rebind a collection's attachment. |

The source preserves the tip's unconditional drawing by using `set_draw(active or node == tip)`. It deliberately validates count3..30/three endpoint divisions to avoid the original zero-stride/history-overflow boundary and initializes the original unwritten previous-rehit field to zero. Preserve those documented undefined-behavior choices; do not claim exact original behavior for malformed edited counts.

One concrete source correction remains: native `it_802A6DC8` writes the right vector into **row 0**, up into **row 1**, and forward into **row 2**. The current source's matrix builder writes right at indices0/4/8, up at1/5/9 and forward at2/6/10, i.e. columns. The existing world-matrix primitive copies row-major `Mtx` bytes directly, so the basis is transposed relative to that native helper. Translation indices3/7/11 are correct. Fix the source basis only with a connected matrix comparison fixture; no template change was made in this audit.

## Existing primitives and concrete blockers

Six collections is an explicit current bound, not proof of eight simultaneous source Chains. A coherent implementation must size/reserve a fixed pool for its intended concurrency, reject exhaustion without clamping, and publish that evidence. Native ItemLink payloads are still allocated by `item_link_alloc_data`; the existing static collection metadata alone is not a complete explicit snapshot owner.

## Minimal connected implementation

1. During candidate preparation, parse each Article's closed `resources capacity N` and `model_root NAME OFFSET` declarations. Validate duplicates, names/hash collisions, capacity and original DAT offsets; prepare named graph roots in the existing owned import arena using the generic import helper. Select source definitions by exact author + source owner node + bank, not physical ItemKind. This needs no donor lookup or facts-format expansion for source-declared names.
2. Add immutable capacity/root metadata to the prepared Item spec. Resolve Link/Tip to closed numeric table ordinals at compile/load time; runtime model loading uses that exact spec/Article table. No tick text scan, native attribute byte arithmetic or authored C callback table. Arrays/graphs and package leases remain pinned while any collection, pending operation or rollback history refers to them.
3. Wire the actual resource consumers to a retained source Item/creator identity: full scene epoch, GObj pool reference/generation, native Item/Fighter generation, spec/bank/layout/parameter identity, collection generation and node index. Use the already substantive source Item status/view and captured creator APIs; `nativeItem_Creator` supports captured NULL Definition identity, but needs source-bank/view checks for authored resource authority. Do not route through `nativeArticle_Creator` or fabricate old logic pointers. Retain the creation-time attachment JObj and guarded actual parts owner.
4. Add only Chain's connected typed operations initially: begin/release; node create/load_model/set_draw; position/velocity, surface line, collision current/last and returned contact data; sweep_point; joint translation/visibility; attachment point/matrix and world-matrix write. Keep ECB sweep distinct from point sweep, CollData.last_pos distinct from prev_pos, and root/path channels distinct from node physics storage. Property getters must not run collision, rebuild matrices or retarget owners.
5. For the smallest route with today's scalar VM, describe matrix reads as twelve F32 output destinations and writes as twelve F32 inputs, using the existing 32-argument/output-mask machinery. The source matrix argument can be expanded into twelve checked cell destinations/reads at load time, or rewritten explicitly when source edits are authorized. If retaining first-class span syntax instead, introduce an invocation-only typed array view carrying declaration/owner/schema/count provenance; validate exact writable F32[12], never expose a C pointer in VM values or persist that transient view. Copy all cells into local `Mtx` before mutation, and publish read outputs only after source/resource continuation guards.
6. Preserve native node GX callbacks and source code-ID Article scheduling. Revoke access immediately on release/fault/retirement; defer storage reclamation until nested sweep/dispatch unwinds. Cleanup must be able to use retained physical identity after logical Item/Fighter storage retires, detach all borrowed links before freeing any JObj, and never regain authored execution authority. Final Item free cancels leaked/partially constructed collections regardless of missing/faulted Destroyed hook. Scene retirement drains/preflights this owner before GObj/creator tables disappear.

Source state arrays are already packed by the Item owner. Resource nodes need their own occupied payload/links/free ordering, ItemLink collision state, mutable JObj/animation graph peers and collection metadata; native graph descriptors remain pinned immutable assets. Validate all peers and quiescence before a packed restore. Copying twelve matrix cells or restoring the Item VM alone is not complete Chain rollback.

## Acceptance before claiming Chain closure

- Actual DAT roots/count and duplicate-name/out-of-offset/type/external-reference failures, with accepted candidate unchanged; prove shared Link/Tip descriptor identity and independent mutable instances.
- Whole Chain Article/helper corpus through real metadata/compiler/VM and native collection/scheduler, including checked arrays and matrix output publication. Control asset/model or stage leaves explicitly in console evidence.
- Constructor failure at every node/model boundary, pool exhaustion, reverse cleanup, idempotent release, owner reassign/remove, deferred Item free, creator reuse, same-address node reuse, fault/retirement during sweep and guarded output unchanged.
- Compare exact node ECB/history, root matrices/flags, tip/non-tip draw policy, attachment matrix setup call order and creator hitbox endpoints against the actual native helpers. Real hidden render/game validation remains separate.
- Roundtrip collection + Item/Fighter/GObj/JObj/AObj/FObj/collision/global peers against the broad oracle, including resurrection/free order and scene transitions. This audit supplies no runtime performance result.
