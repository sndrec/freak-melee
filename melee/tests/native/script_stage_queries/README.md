# Stage query contract

This hidden console cohort executes the actual compiler, metadata preparation,
Fighter and Item actors, VM/catalog dispatch, physical GObj pool, and source
lifetime guards. The selected package/DAT publication and unrelated engine
operations use the existing scheduler fixture boundary.

The native initializer, ECB preparation/interpolation, subdivision, bounding
orchestration, floor/ceiling callback dispatch, sweep wrapper, segment wrapper,
and vector arithmetic are mechanically extracted from current source. Collision
line resolution (`mpColl_80046904` and `mpCheckMultiple`), stage callback lookup,
dynamic surface attributes and bounding storage are controlled leaves. This is
not collision solver, DAT import, renderer, game, or recursive scratch acceptance.

Comparisons cover raw flags separately from the native Boolean, exact low-four
category bits including full-width integers, repeated native substeps, ordered
arguments and source VM calls, malformed types/arithmetic, scene/schema changes,
faults, and retirement during an actual native stage callback. The callback's
retirement/fault injection is a fixture action, not a claim that stock stage
callbacks currently execute authored scripts. Native shared scratch remains
serialized; no parallel or recursive guarantee is asserted.

Run `run.py --compiler <LLVM clang.exe> --output <fresh A: directory>`.

The cohort contains 86 native comparisons and 10 VM invocations, including actual
Fighter and Item arithmetic faults, argument evaluation once, and retirement
while the real sweep dispatches a native stage callback. Free/reallocate at
the same GObj address does not publish the old caller's result. The selected
Item spec comes from the actual published Fighter program.

The registered native callback audit found actor-dependent categories 1/2/3
in `gryorster.c`. They are rejected before entering the sweep, including signed
and full-width inputs whose low nibble matches. Registered callback source
files are pinned as audit evidence; they are not executed by this cohort.
The remaining category audit establishes current actorless-pointer admission,
not arbitrary future callbacks or full stage collision correctness. Native
stage callbacks and gameplay have not been modified.

## Point-to-island comparison

`stage.compare_floor_islands` executes actual native vertical floor probes and
island endpoint-bound scanning. A separately extracted reference at `762ce905a`
changes only function/inter-function names; its body hash is in the receipt.
Twenty-four comparisons exercise missing/identical/different islands, a disabled
second probe and static/dynamic endpoint coordinates. The actual compiled helper
also verifies ordered expression evaluation and Bool/Float state publication on

preserve outputs. Segment intersections, endpoint coordinates and observer
changes are fixture-controlled. This establishes the native query sequence and
publication contract, not real moving-stage geometry or whole Yoshi CPU behavior.

The compiled `CpuFloor` helper composes `stage.read_floor` with
`stage.cpu_floor_excluded`, preserving short-circuit evaluation when there is
no contact. Its Bool result, floor-iteration count and native bounding scratch
are compared with `ftCo_800A0FB0` and its exclusion predicate pinned to

cover 16 contact masks, both segment directions, five stage kinds and four

segment intersection, line endpoint resolution and dynamic response leaves
remain controlled. This is compiled predicate parity on that geometry corpus,
not full authored Yoshi/Bowser CPU scheduling or real stage solver acceptance.


## Connected floor following

`floor_follow_cases.h` calls the actual extracted floor projection, positive and
negative adjacency selection, endpoint/kind/flag reads, rounded square root, and
signed traversal. It compares the typed binding's publication recipe with direct
native calls over flat/sloped chains, wall gaps, ceilings, secondary links,
hidden/disabled links, missing terrain and exhausted chains. Fighter helpers and
Article signals execute the compiled ten-argument operation with persistent
output destinations. The fighter is unchanged by the query. Invalid argument
shapes, scalar types, source generation/scene, and initial endpoint storage fail
without publishing outputs. Native stage topology is controlled and valid; this
cohort does not validate arbitrary malformed/cyclic stage graphs or whole DK
Hand Slap gameplay. There is no retirement observer inside this pure geometry
path, so only source admission is deliberately varied here.

The native helper now uses an addressable local for its rounded Float store,
rather than an invalid pointer before a PPC stack-matching array. The original
arithmetic/traversal is retained; the wall accumulator is initialized explicitly.


## Dynamic point-to-island bounds

`island_bounds_cases.h` compares the actual typed operation with native floor
island lookup plus `mpIsland_8005ACE8`, separately extracted at `762ce905a` with
function/call names renamed only. Success, missing floor/island, static/dynamic
endpoints, origin fallback, and exact query/endpoint-call counts are compared.
The actual compiled Fighter helper verifies input expression evaluation once
and five persistent output stores; Article signals exercise both static and
dynamic results. Invalid scalar types, overflow, source identity and selected
island joint are rejected. Fixture observers retire/change source schema or
replace geometry during the floor probe or endpoint refresh; none publish
partial outputs. Intersection/endpoint coordinates and those explicit observers
are controlled leaves. Native map topology is valid; malformed arbitrary graphs
and full DK CPU/gameplay behavior are outside this cohort.

Stage events execute the actual Stage_Event dispatcher with a controlled provider. The cohort checks full UInt32 channel IDs, exact Float payload bits, provider absence/results, VM routing and source retirement. This is not a stock-stage conversation gameplay test.
