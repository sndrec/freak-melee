# Direct resource frontend cohort

This console fixture links the rebuilt native parser, declaration index, compiler, bytecode, storage and Item program preparation. Synthetic owned Article descriptors, root tables and four-joint facts isolate frontend acceptance from DAT import and graph construction.

The grouped source covers collection begin/count/release; both create arities; exact owner root ordinals; node/collision fields; draw/attachment/contact/effect calls; prepared literal SRT/quaternion/visibility paths; and matrix methods taking exact owned Float[12] arrays. Matrix arguments lower to immutable I32 declaration constants only inside these methods. Preparation verifies sorted owner recipes, aggregate rebasing and failure preservation.

The actual VM uses a recording host to verify one evaluation of a dynamic resource index before an effectful assignment RHS, full-width integer inputs, copied declaration constants, F32 output registers, zero publication on healthy false and no output writes after caller retirement. These controlled calls prove compiler/VM marshalling, not successful native resource execution. An explicitly unavailable resource runtime rejects direct Read/Write/Invoke without changing outputs.

Negative sources cover foreign roots and Fighter ownership, path grammar/depth, scalar/output types, readonly fields, matrix shape and metadata capacity/reservation placement. Runtime collections, ItemLink/graph allocation, collision geometry, effects, actual Item actor lifetime, rendering and gameplay are outside this fixture.
