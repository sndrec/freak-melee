# Owned-source feedback contracts

Run with a fresh A: output directory:

```powershell
python tests/native/script_feedback_contracts/run.py --compiler A:/FreakMelee-test-archives/baseline72/compiler/clang.exe --output A:/FreakMelee-test-archives/script-feedback-contracts-review
```

All compiler/console subprocesses are hidden. No game or global build is run.
The fixture links actual feedback binding code, complete descriptor catalog extraction and effect
ABI classifier. SourceAlive/SourceFighterLayout and native reflector/part-mapping/
Item bone-effect bodies are extracted unchanged from current production sources.
Actual callback lifetime membership and native match-pool references with a full-width scene epoch are used.
Selected SourcePackage, actor view/storage/schema identities and native rig/data
publication are controlled boundaries, with exact relationships validated by
production guards. This does not claim actual package preparation or VM/actor
attachment; VM/package/actor acceptance is separate from this contract fixture.

Reflector creation compares full Fighter results with the actual shared primitive.
Wind uses a nonidentity semantic-part map and checks facing offset and scalar
arguments. Item bone effects compare indexed tables and child-chain fallback,
both modes and native joint selection with the actual existing primitive.
Effect 1276 has the admitted single-JObj ABI. A single-JObj request for 1146 is
rejected before spawn; its admitted Joint+F32* scalar form passes an immediately
consumed scalar with exact value. Graphics/effect/wind/joint-position leaves are
controlled and do not render. Ownership mismatches reject field-only controls without mutation. Item tests use
physically live native Item model metadata; they do not claim owned Item attachment.
Receipts record source/input hashes and command.

The shared script_form_feedback extractor supplies the unchanged descriptor and
source guard contract plus native dispatcher argument proof. The admitted 1276
and 1146 signatures are checked against that independently extracted source proof,
as well as the production classifier. No handwritten success descriptor is used.

Final scoped result: 848 checks. Every compiled unit uses -Wall -Wextra -Werror;
input hashes are captured before compilation and checked after execution.

argument copies for recipe `0x3FF`, 17 malformed/type/nonfinite/other-recipe
cases, six pre-spawn ownership failures, and nine post-spawn retirements
(generation, epoch, program, storage, layout, parameters, rig, userdata and

not undo the native construction. The constructor leaf is controlled here;

`script_position_effect_abi`. Neither fixture renders effects or accepts a
complete Yoshi match.
