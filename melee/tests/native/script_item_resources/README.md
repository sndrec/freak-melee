# Connected source Item resource kernel

This private console cohort compiles the actual resource, resource-scene, resource-model and resource-animation kernels against frozen source/library inputs. It imports a real Link Arrow root, prepares a source resource recipe and program, publishes the private selected package, and attaches actual Fighter/Item actors. Item animation and resource construction execute through the real compiler, actor and VM. The recipe reserves native part 76: Link's 75 owned joints plus its one imported omission part.

The resource translation unit receives explicit external symbol substitutions for stage/point/floor geometry and effect dispatch. Line speed executes source-identical `mpGetSpeed`, `mpRemap2d`, `mpLib_80054ED8` and map/line/vertex getters on controlled stage tables; only their symbol names are changed to keep this private corpus separate from linked stage storage. Collision initialization remains the native mpColl bodies. Geometry controls write deterministic native CollData and can revoke a collection inside the real active-operation fence. The unused effect control aborts. No healthy source guard, actor status, lifecycle result, collection algorithm or rollback algorithm is replaced. The synchronous release case is an intentional external observation control, not a claim that stock geometry invokes callbacks.

The line-speed corpus compares 256 native remapping results, including coincident previous vertices and points outside the segment, with the resource operation. It exercises successful delivery and healthy false zero publication through the real compiler, Item actor, VM and writable float destinations. `-1` enters the unchanged native sentinel path even with absent stage tables. Other negative or out-of-range IDs are refused before the native predicate, whose invalid-ID branch deliberately hangs. Disabled/hidden lines preserve native false without requiring unused vertex tables. Enabled visible lines require the map, line table, selected MapLine, vertex table and both indices within the actual vertex count. Primitive false preserves the caller's Vec3; the public interpreter query retains its existing false-and-zero output contract. No geometry numerical restriction, allocation, callback or arbitrary dangling-pointer safety claim is added.

The older standalone `article_resource_geometry_test.c` and snapshot-overlay runner are historical generated-oracle fixtures, absent from the current CMake targets. They have pre-existing ResourceAnimation path-ABI and resource-owner preparation drift and are not claimed to pass against current production. Their line-speed leaf is controlled. This connected cohort supplies the current actual line-kernel and owned Item/resource evidence; it does not migrate or certify those historical suites.

Transition input staging includes unchanged runtime/heap units to set their private tables. Item payloads use the actual tracked main heap; Fighter payloads, parts, attribute backup and DObj tables use their actual fixed native Fighter slots. Standard HSD classes are initialized through real ClassInfoInit before preparation. The attachment rig is a controlled two-joint graph built by native HSD constructors; the resource graph is the imported Arrow graph. Same-kind duplicate runtime rows exercise the actual first-match getter, not distinct-kind package deduplication. Production package loading, Item construction, scheduler and renderer fidelity are outside this proof.

The extended private preflight passes **2,654 checks across 12 cases**, including **256 native line-speed comparisons**, **16 line-domain/geometry refusals** and **24 Item VM output cases**, with **12 graph loads**, **4 controlled geometry visits**, **2 completed history frames** and **1 restore**. Final metrics and exact pins are recorded in the fresh receipt. Cases cover Begin/Create bounds, node geometry, full identity captures, graph replacement, attachment revocation, borrower cleanup, logical Fighter detach with retained physical-rig teardown, normal endpoint removal, explicitly injected orphan ownership, deferred release and fixed backing. Tick operations compare actual OS heap free space; no heap-growth path is substituted.

ResourceAnimation_Prepare() now derives allowed animation tuples from the compiled source and runs with Retire in production order with its package leases. The default Arrow run retains static-root controls and rejected Add behavior. A second run imports Link's actual Boomerang root and joint animation. Its five source joint-animation methods run through the Item VM and match the original HSD graph, controller and FObj-track state across 39 operations, including fractional frames, changed rates, replacement and removal. Three altered path/bundle/recipe cases reject before output publication and leave the graph and operation count unchanged. Both runs retain the existing resource/history checks; they pass 7,031 checks across 25 cases in total. Material/shape playback and active-controller rollback are not exercised here.

Real Regions/Pages restore covers the collection registry, payload/graph pools, allocator, actor storage and tracked heap. A completed frame replaces a graph, changes node geometry and its world matrix, and executes an Item VM phase. Restoration compares complete captured-region hashes, root pointers, IDs, generations, pool counts and owned storage; deterministic replay produces the same observation. Retained history blocks scene/model/animation retirement. Immutable imported descriptors and host controls remain outside captured memory. This is a bounded history cohort, not whole-match rollback acceptance.

There is no draw traversal or lazy-matrix allocation exercise. Native unmanaged JObj addresses have no per-address generation; admitted owned graph pool tokens guard replacement. No GPU/audio/game launch or effect allocation is covered.

Two failed-constructor attachment cases execute the actual physical cancellation and borrower-detach kernels on genuine imported Arrow graphs: a retained attachment from an older logical life is cancelled immediately or while a real active-operation fence defers graph disposal. Exact invalid GObj/Fighter references are refused. Reserved part, capture anchor, normal and thrown hitbox borrowers are detached before graph/payload retirement.
