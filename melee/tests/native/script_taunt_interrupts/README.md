# Shared taunt interrupts

The actual `ftCo_AppealS_IASA` body executes through the real source catalog,
compiler, VM and Fighter actor. Its original console branch is independently
extracted as the ordering reference. The fourteen native input decisions are
controlled leaves, so this proves dispatch, `allow_interrupt` gating, exact
success short circuit and source lifetime barriers, not controller/attack logic.

Every input position is tested with a false result after actual interpreted
`cpu_capture_decision` returns false. Controlled leaf continuations then inject
physical removal, a genuine nested VM division fault, native generation change,
program identity change or userdata replacement. The actual common routine must
stop before the next input. Outer VM cases prove retirement/error prevents its
following state write and preserves the caller's output.

Owned package/motion data and physical Fighter construction are controlled.
Actual Fighter actor publication/dispatch, source storage, scoped VM scratch and
GObj fixed pools execute. Item actor implementations are linked dependencies;
this Fighter-only fixture makes no Item execution claim. Unrelated gameplay
primitives reject explicitly.

The same fixture checks `animation.clip_length` using the exact newly added
Kinetics query-entry body, with sibling kinetic operations explicitly rejected.
Actual native `ftData_80085E50`/`ftData_80085FD4` and `lbAnim_8001E8F8` bodies are
the reference. Controlled owned animation rows cover resident/missing clips,
F32 bit preservation, dynamic helper arguments, invalid widths/indices and
missing table rejection. This does not claim real FigaTree import/loading.
No stock character taunt handler, retail DAT, full DrMario or game acceptance is
claimed. Run the hidden standalone `run.py` with an MSVC-target clang compiler
and a fresh `A:` output directory; it fingerprints production inputs.
