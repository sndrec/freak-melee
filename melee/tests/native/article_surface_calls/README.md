# Generated article surface and asynchronous effect calls

The compiler fixture emits complete modules in both action and motion-state
routes. It checks call arity, effect-ID types, literal modes, bounded joint paths,
read-only restitution, and the language's ordinary Bool/Int coercion rules.

Both module fixtures run the actual generated article callback over 1,024
combinations of response codes, reflection results and restitution values.
They check full-width IDs, exact paths/modes, single dispatch, state field types,
stop-flag isolation and rejection when required Host operations are absent.

Surface functions and effect queues are controlled boundaries here. Actual
native surface and enqueue bodies have separate engine checks; compiler tests
do not establish visible effect or full Ice Climbers gameplay parity.
