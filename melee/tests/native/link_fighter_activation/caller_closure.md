## Validation and limits

`prepare.py --snapshot --output [--iso]` normal clones/imports both independent
sources, generates and compiles actual DLLs, loads them against exact current
copied-base metadata, checks every Definition callback and original motion phase
pointer, all article callbacks/signals/projectile policies and asset-kind coverage,
then bundles and verifies isolated packages. It never installs or launches a game.
The frozen input manifest and all source/module/project hashes are receipts.

No additional generic policy API gap is presently identified. Metadata blockers
are resolved in real51 copied bases. Final51 normal import/generation/DLL/package
validation passed721 Link and776 Young Link assertions. Shared smash startup
continuation liveness after nested motion/animation is root-owned validation; the
controlled event invocation here does not claim that boundary. Whole hidden/muted drawn gameplay, CPU behavior, rendering,
all costume graph installation, rollback/network and actual results scene remain
unaccepted. Bow fighter phase matrix and non-unit Boomerang flight replay are
still separate source evidence gates; previous component acceptance is retained.
