# Direct form feedback ABI and lifetime fixture

```powershell
python tests/native/script_form_feedback/run.py --compiler .local/baseline72/compiler/clang.exe --output A:/FreakMelee-test-archives/script-form-feedback-new
```

Use a fresh private A: directory. Compilation/console execution is hidden and
bounded; no game, global build, user project or content store is involved.
The receipt contains commands, input hashes and generated source proof.

`extract(root,out)` is importable. It emits `source_contract.inc` with the
actual complete binding catalog/Descriptor getter, SourceAlive/SourceFighterLayout
guards and part mapping (only the private guard error name changes), plus the
actual dispatcher argument classification and per-case source fingerprints.
The 65,536-ID matrix reads real `efSync_Spawn`, `efAlt_Spawn` and
`efAsync_Dispatch` cases, includes grouped labels, excludes forwarded/erased/
nonmatching argument paths and verifies immediate scalar-pointer use. The
RotationZFromPtr helper is also checked for immediate dereference.

The executable links actual feedback/classifier units, actual callback registry
and native pool bind/allocate/free/reuse. It controls the selected package/program/
storage view and native effect/wind/world-position leaves. This proves argument
admission, guards and native vararg values; it does not run native particle
constructors, a full VM scheduler, asset import, renderer or game.

Tests compare raw104/raw43 against deliberately different semantic mappings,
exercise every admitted effect ID, verify scalar bits and a local address distinct
from caller args/Fighter fields, and verify exact position wind without joint
sampling/facing adjustment. Existing semantic wind retains its joint sample and
facing offset. Unsupported ABI, wrong kind/count/type, absent joint, stale epoch,
fault and unbound data fail without output publication. Thirty-nine injected
mutations across effect creation, position sampling and wind creation cover
storage/view/program/layout/parameter/rig/parts changes, physical generation and
same-address/same-spawn-ID pool reuse. Completed native effects/wind remain counted
when the caller retires; a failed intermediate sample does not emit wind.
