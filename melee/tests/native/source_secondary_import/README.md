# Owned secondary descriptor import

This cohort reads real private Link/Young Link source facts and DATs and prepares
owner-scoped named Arrow roots at exact special-attribute offsets 36/40. All
descriptor import tests precede OS/HSD heap or class initialization. It verifies
actual cache reuse, preservation of prior allocations, exact
copied names and independent source owners sharing the same physical Article.
The Arrow special-attribute importer already caches these graphs, so creating
named views does not allocate duplicates or change its import cursor. The
uncached synthetic legacy regression separately proves real arena advancement.
The `costarring`/`liquid` names collide under FNV1a; the table keeps their exact
bytes and distinct descriptors. No Article hash table or primary model alias is
used. Declared NULL, malformed offsets/names, duplicates, late roots, capacity,
missing asset and secondary-animation declarations reject. Absent declarations
leave a clean empty view. Import failure discards its unpublished candidate;
import cursors are not rolled back in place.
The NULL-admission case deliberately redirects a copied Article's attribute
source to a real NULL word in the immutable DAT; the retail Arrow attribute
block has no NULL words. This controlled invalid-descriptor case is separate
from the four actual owned root imports.

The actual metadata validator accepts static `model_root` declarations only
when their immutable asset records match the exact owner, ordinal count, name,
special-attribute offset and non-NULL graph. The cohort checks each mismatch
independently. Existing advanced multi-root and animation import regressions run
unchanged, including their defined nullable-root behavior. Ordinary source roots
reject declared NULL. This cohort does not execute the new Item model VM APIs.

After import, a separate explicit bootstrap initializes a real 16 MiB HSD heap
and the five standard model classes. The actual `NativeArticleModelPool` admits
all four root alternatives in one bounded owner with two live graphs plus one
replacement graph. Tests construct real JObj/DObj/PObj/MObj/TObj/TEV graphs,
traverse lazy scale matrices, reject an ordinary heap root for matrix claims,
reject exhaustion without changing backing/metadata/IDs, reuse freed capacity,
and require removal before release. The byte snapshots prove rejected-operation
preservation; they are not rollback save/load or global peer capture evidence.

The hidden compiler/console use copied actual native libraries, exact native
link dependencies and copied/fingerprinted DLLs. Current model-pool source is
compiled explicitly alongside the shared root-declaration parser. Production/SDK source inputs are copied and hashed before
compilation; unrelated live-source changes are reported separately and do not
invalidate the tested immutable snapshot. Other linked game units are not
rebuilt by this runner. There are no replacement engine
functions, shared builds, graphics/audio initialization, game launches or user
draft mutations. The SDK duplicate `MTXPerspective` array declaration warning is
suppressed; all other fixture warnings are errors. Static descriptors remain
pinned in the character/blueprint owner arenas. Animation, resource collections,
rendering, Item scheduling and full rollback ownership are outside this proof.
The blueprint-owned import-cursor branch is implemented and source-reviewed;
this Arrow corpus exercises the character-owned branch.
