# Prepared fighter dynamics

Run `run.py --compiler <clang.exe> --output A:/<fresh-directory>`. All compiler processes are hidden. The receipt pins source, headers, generated body extractions and compiler hashes and rejects an input change during the run.

Three independent programs compile through the real frontend and Fighter preparation. Real actor storage, typed event payloads, synchronous VM dispatch and the registered GObj pool execute the actual dynamics scheduler bodies. The native class-descendant predicate, collider preparation, descriptor free-list body, dynamic-bone unload and joint-flag clearing are mechanically extracted from production. The HSD class information and fixed joint/descriptor graphs are controlled valid resource data; no fake successful actor/status/lifetime dispatch is used.

The source matrix covers zero through four sets, both ordinary and Flatzone stages, Bool floor policy, and signed thresholds including I32 minimum/maximum without clamping. It checks delivered set/count, a genuinely missing prepared hook's zero default and source wind bypass. Three animation-reset cases execute actual E7B4 and CB40, preserving the common reset path. A separate 120-pair matrix compares ordered thresholds, bone IDs, position/floor/ground policy and temporary root scale against the unchanged native bodies at commit `45ac45dce93fd6a8540f1686fcd14e445341787b` for Mars, Peach, Mewtwo and both Koopa kinds.

Reached authored property writes inject retirement, same-address GObj reuse, userdata/class/native generation/data substitution, actual dynamic-bone unload, descriptor-head/count/next/joint changes, root/class replacement, attachment-mask/bone/collider changes and nested VM fault. Each runs at the first and second set. The test checks that no subsequent solver/matrix stage executes, and that Flatzone scale restoration touches only a physically unchanged root. A direct division fault and malformed initial counts/chains are also covered. These injected observations do not imply normal field reads cause native reentry.

The ground-policy cohort adds 12 declared-policy/ground/chain combinations, 17 physical/program/root/graph mutation boundaries and a real VM fault. It tests both enabled and disabled policy results before solver execution. The complete fixture reports 2,808 checks, 253 cases and 120 native comparisons.

The numerical `lb_8001044C` solver, world-coordinate transform, HSD matrix construction and unrelated animation/engine leaves are controlled. There is no solver numerical parity, DAT import, graph construction, actor-only rollback or gameplay claim. Native JObj and dynamics-node allocations have no individual generation query: identity checks retain pointers/class/links, but cannot detect arbitrary free-and-recreate at the same native address with identical metadata. Source `dynamics_wind` remains unsupported; its generic source baseline is not authored-policy migration. `dynamics_ground_collision` now executes a prepared Bool hook when declared.

Changed scheduler bodies compile with warnings as errors except the exact E7B4 `var_r3` warning independently reproduced under identical flags against the pinned pre-batch body. The runner verifies that it is the sole changed-body warning. The full fixture also compiles the unchanged CB40 pointer/integer casts in both current and reference bodies; those legacy casts are not treated as new lifetime behavior.
