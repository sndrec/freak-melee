# Owned secondary animation descriptor import

Private real-library cohort for owned Link and Young Link Boomerang animation
bundles and Ness's material-only Yo-yo animation. Descriptor preparation occurs before HSD heap/class initialization.
No production function is substituted. A controlled duplicate facts row refers
to the same physical Article under a distinct source owner/name; this tests
immutable ownership, rather than an additional retail Article.

The cohort checks the exact typed triplets at attribute offsets 76/88 and roots
68/72, cached descriptor identity without arena rewind, source-name ownership,
the eight-bundle limit, ordering, alignment, overflow, extent and declaration
rejection. Exact valid `model_animation` declarations pass compiler metadata
validation; descriptor preparation alone does not prove runtime playback.
Names such as `and`/`not` pass the importer's identifier-shape parser; compiler
keyword/symbol admission is separate. They fail compiler namespace validation.
The first review run incorrectly expected importer rejection of
these keywords; no production policy was changed to satisfy that expectation.

Existing low-level array/NULL animation import regressions use explicitly
synthetic DAT containers. Additional synthetic sparse matching, malformed
stream and cycle cases check success-only census output. Valid CON, LIN, SPL0,
SPL, SLP and KEY streams are evaluated with the actual public FObj request and
interpret functions on a stack leaf. A recording callback checks scalar values
and timing, including KEY waits and terminal values without a final wait.

No HSD bootstrap, pool-object allocation, native graph/controller attachment,
graph playback, shader/GPU draw, Item scheduler/VM, gameplay or history acceptance
is claimed. A successful descriptor census is not complete runtime channel or
capacity admission.

The original foundation receipt contains 421 checks before public metadata
admission opened. The refreshed public-runtime receipt contains 413 checks,
24 cases, five entity preparations and 40
native scalar frame comparisons. Each actual Link/Young Link bundle at 76/88
has one applied controller, one track and zero uncovered flags for its matching
root at 68/72. Those tuples describe one application, not cumulative pool demand.

Run with `run.py --compiler CLANG --link LINK_DRAFT --young-link YOUNG_DRAFT
--ness NESS_DRAFT --output FRESH_A_DIRECTORY`. The runner copies source, inputs and rebuilt native
libraries privately, records their hashes, compiles the current importer/census
units directly, and never invokes a shared build. Refreshed archive:
`A:/FreakMelee-test-archives/source-secondary-animation-import-oct09-public-closure`.
