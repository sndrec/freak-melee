# Ground controls connected fixture

Run `run.py --compiler <MSVC-target clang.exe> --output <fresh A: directory>`.
Compiler and fixture subprocesses use CREATE_NO_WINDOW. The receipt fingerprints
the actual compiled inputs and the pinned pre-guard reference revision.

The fixture compiles authored helpers through the production source compiler,
catalog, bytecode, VM, Fighter actor, storage and fixed GObj pool. It extracts
the twelve actual common input predicates, their common entry bodies and the
actual source/package admission guards. It compares native and interpreted
results, input profile decisions and field/leaf ordering. Separate healthy
entry comparisons use revision b9ec6b132325f7b5b4ba45d8f62537265158528e.

The grouped cohort also extracts the four unchanged common ground-special
checks, side-special entry, facing update, source friction selection and floor
friction projection. The lowest stage material coefficient is controlled.
Actual authored special hooks execute nested in the same Fighter VM. Cached
input ages, facing thresholds/NaN, friction selection, native momentum fields,
short-circuit order, output withholding and synchronous source lifetime changes
are compared without stock special-handler delegation. Missing hooks are
prepared as an actual source variant and retain native handled/no-op behavior.

The reused attack extractor's field-write anchor now matches only the position
assignment, preserving the existing landing-overwrite and removal tail. This
repairs a stale extraction assertion; the native scheduler source is unchanged.

Motion delivery, animation, held-item classification/use, angle calculation,
common flags, package publication facts and graphics/hardware leaves are
controlled. Mutation leaves deliberately provoke actual nested VM faults,
GObj retirement, generation changes and userdata replacement. This is a
continuation contract test, not evidence that ordinary field reads reenter.
The actual actor, storage, VM and physical pool are not success stubs.

No imported DAT, complete GW gameplay or specialized Ness Yoyo entry is tested.
The common smash input entries do not install stock-specific handlers.
Source `up_smash_enter`/`down_smash_enter` events remain unsupported by the direct
Fighter hook table; examples/ness_wip.fms contains the former. Unrelated native
binding families explicitly reject invocation.

The final matrix contains 777 comparison pairs: 768 native/VM input/profile
samples and nine unchanged healthy entry comparisons. Every mutating check also
has an actual VM-fault tail test and a direct native-output withholding test.
There are 109 grouped cases including both guarded entry stages, physical
retirement, logical fault, generation and userdata identity changes, pickup
continuation, crouch, invalid shapes and foreign Fighter observations. The
final receipt contains the exact check and invocation counts.

The previous counts above describe the retained ground attack/control matrix;
the receipt separately reports the additional special comparison/case counts.
Hook field writes and motion/animation leaves are controlled boundaries; this
does not prove complete special moves, rendered models or retail stage assets.

Special lifetime injections occur inside a controlled plain position writer;
that callback-free production write is not claimed to cause native reentry.
The enclosing special check must withhold its Bool and stop the outer helper's
tail after the nested hook returns. No rollback or interruption at an arbitrary
statement inside that artificially interrupted hook is claimed.
