# Mutable event value records

This pure console cohort uses actual event metadata, source/ProgramIndex/body compilation, bytecode, VM and payload kernel. The native lifetime provider is controlled. It does not substitute a successful compiler or payload operation, and does not establish Fighter/afterimage rendering or the Execution bridge's final native commit order.

Trail has fourteen I32/Float fields and no anonymous arguments. Writes are copied invocation values, not native pointers or actor state. The cohort checks exact native offsets/bytes, unaligned input/output buffers, NaN and negative-zero preservation, readonly-body local/record assignments, actor-state write denial, helper/callback scope, nested frame suspension/resumption, stale and retired handles, scene identity, canonical widths and unchanged output on export failure. Ordinary anonymous history payload bitcasts remain covered.

The generic kernel supports explicit Bool1, I32/U32/Float4 and I64/U64/Double8 native widths. The shipped Trail schema exercises I32/Float; no synthetic native callback descriptor is substituted to claim other schemas. Padding is retained from the seed bytes; the actual Trail layout has no intervening padding.

Use frozen clang and a fresh private A: output directory. Sources, headers, compiler and README are fingerprinted before the hidden strict compile/run.
