# Generic source color bindings

The fixture compiles and executes real owned palette helpers through the actual Fighter and Item actors, VM, execution contexts, top-level binding catalog and property dispatcher. Five costume IDs test the three explicit palette choices and ordinary/custom fallback, using owned I32 parameter channels. RGBA packs low8 channel bytes as signed I32 bits without float conversion; signed/unsigned64 values retain their low bits. `model.base_scale` reads `co_attrs.model_scaling`, independently of instance scale. The combined scale expression preserves native F32 arithmetic.

Diffuse color changes the live HSD material graph through actual `ftMaterial_800BFB4C` / `it_80278574`, rather than a cached Fighter palette field. The two native traversal rules are compared directly: Fighter skips instance children, while Item follows the constructor's ordinary child/next/parent graph. These shared primitive bodies, native JObj flags/DObj getters and class ancestry are mechanically extracted from current source. Controlled JObj class records represent already initialized native classes; malformed class initialization is not bypassed by production guards.

Outline fields, secondary-material preservation, instance width, Item controller tint/enable and material opacity use their native fields. Invalid width (zero/nonfinite) and opacity (outside0..255) writes retain the native no-op. Item layer enabling calls actual `articleModelLayers_Bind` with real live graph/table admission; unavailable lists leave `item.layered` false. Particle/null graph material traversals retain their native no-op. Outline visibility invokes the actual SourcePackage-owned lookup validation routine; it can run from any callback with a initialized current costume. Slot admission retains signed/unsigned width so a wide integer cannot wrap onto another owned lookup.

The console links actual fixed Fighter/GObj pools, source metadata/preparation, actors, storage and VM. Source package/facts/DAT descriptors and physical construction are controlled, with separate primary graphs for the Fighter and Item. Native material/layer/outline routines are real; unrelated native families reject explicitly. It verifies a foreign storage-parameters pointer rejects before mutation/publication. A pre-call change to an immutable parameter identity is not portrayed as mid-call retirement: capture establishes the current baseline, and no whole-bank hash was added to manufacture that expectation. The material routines have no authored callback invocation, so this fixture does not claim native reentry coverage.

The source negatives reject float RGBA channels, float packed diffuse colors and writes to readonly costume index while preserving the accepted bank. Target controller-color queries remain outside this slice. No original Game & Watch DAT import, GPU frame, complete Game & Watch/Dr. Mario activation, or launched game is claimed.

Run `run.py --compiler <clang.exe> --output <fresh A: archive>`; all subprocesses are hidden and inputs are fingerprinted. The README and receipt describe these current color/common-property bodies, not the earlier rotation fixture used as a construction substrate.
