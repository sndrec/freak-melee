Fresh A: output only. Compiler and console processes use CREATE_NO_WINDOW.
No game/global build, production change, template or user-project write is made.

The actual compiler, catalog, typed argument marshalling, Transition_Invoke,
SourceFighterLayout, VM/execution, storage and physical callback lifetime guards
are linked. A compiled root helper invokes `state.enter_at_speed` then writes
state, so failed native continuations also prove the following source statement
stops. The selected SourcePackage, publication tables and actor view/status are
controlled boundaries; their exact bank/data/layout/storage relationships are
checked by the actual ownership validator. This is not package or actor-attachment
acceptance.

The native motion-installation leaf captures all seven actual ABI arguments.
The fixture compares motion, U32 flags, exact F32 frame/rate bits, zero blend,
NULL target, call count and ordering. Representative finite frame/rate values
include signed zero, one, negative, variable fractional and subnormal values.
Integral motion widths and numeric-to-F32 marshalling are checked separately.
`enter_at_speed` never starts animation implicitly; existing `state.begin`
retains motion-before-start order. Native graph/animation installation is not
executed, so this does not assert every animation accepts every numerical input.

Physical removal, generation replacement, logical storage retirement, actor
fault and owned-data replacement at the reached native callback reject output
publication and suppress subsequent authored writes. Invalid motion type/range,
context/arity and inconsistent package/bank/table/view/storage ownership reject
before mutation. Unrelated binding families explicitly return unavailable.
Input hashes and exact hidden subprocess commands are saved in receipt.json.

Final scoped result: 83,771 checks, 3,630 direct/VM argument pairs and 3,642
VM invocations. All units compile with -Wall -Wextra -Werror. The source catalog
requires integral motion expressions at load; native runtime rejection also
checks non-integral values and high-width/out-of-table motion IDs defensively.
