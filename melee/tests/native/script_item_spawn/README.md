The runner requires fresh A: output, uses CREATE_NO_WINDOW and120-second bounds,
and preserves exact commands, generated source, compiler/source/header hashes and
logs. `extract(root,out,overrides=())` reuses the frozen scheduler extractor and
can exclude named controlled binding leaves for connected binding tests. It does
not modify the scheduler fixture or production code.

The current held-center regression uses a stable selected source package with
owned CustomFirst data/rig facts and executes the real SourceAlive and
SourceFighterLayout guards. The general asset/spec/model leaves remain controlled;
no ownership guard is replaced with successful placeholder behavior. The grouped
public held-center compiler/VM contract is covered by `script_held_center_factory`.

`A:/FreakMelee-test-archives/script-item-spawn-review/receipt.json` passes24 cases /
3149 checks, including1024 actual constructor/free cycles. All seven public
factories execute: Create, Projectile (default and explicit launch), HeldAtCenter,
Attached (including no-directive defaults), AttachedPresentation, PullHoldable and
Food. Tests check native payload/state/creator/recipe identity, exact setup order,
shared presentation follow behavior, inventory assignment and food velocity.

Actual FMS compiler/storage, Fighter/Item actors, receiver/shared execution/VM,
GObj generation/proc/userdata lifetime, public Item_CreateAuthored/Item_CreateEngine,
internal constructor, state setup, pickup/removal and source holdable pickup bodies
run. Source callbacks execute their real authored code. Factory guard tests retire
the logical Fighter caller during Spawned, state, appearance, Created, debug,
update, Launched, picked-up and inventory stages. Each preserves the surviving
native child, stops subsequent setup and leaves output unpublished. Faulted-child,
failed selector, failed Spawned write, invalid state/bone/recipe/source and reused
GObj rejection are separate cases; unpublished constructor failure frees its Item.

The fixed Item payload allocator/model nodes, immutable spec getter/selection,
assets, color-overlay initialization, initial motion leaf and unrelated platform /
draw/audio/collision leaves are controlled. The controlled initial-motion leaf
copies native spawn position/facing/owner/velocity; it does not claim full collision
initialization. The source selector sets identity/assets and calls the actual Item
actor Attach. Immutable preparation/publication is the separate `script_item_program`
fixture. This is no game/render/retail archive parity or whole snapshot claim.

The 2026-10-10 projectile migration regression executes the actual
`nativeItem_CaptureCreator` and `nativeItem_Creator` bodies. The older controlled
creator helper did not initialize the physical pool reference now read by the
real constructor, causing an access violation. The runner replaces those

generated headers. The updated all-factory cohort passes 24 cases / 3,150 checks,
including the existing 1,024 constructor/free cycles; no production constructor

The factory fixture calls native APIs with substantive live interpreted caller
views; it does not claim authored catalog expression coverage. The separate
