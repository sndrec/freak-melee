# Connected source Item model cohort

This private fixture imports owned Link and Young Link DAT descriptors, compiles real model_root
source, publishes the prepared program, and runs model operations through actual
Item actor/VM/native bindings/scene storage and HSD graph primitives. Runtime and
heap private transition tables receive controlled inputs; no production function
is replaced. Item userdata construction/cleanup is controlled, rather than the
complete native factory/scheduler. No game, GPU draw, Workshop or full history
restoration acceptance is claimed.

The same source cohort runs in separate processes against actual owned Link and
Young Link DATs, importing Arrow roots at offsets 36 and 40. No manual root-table
substitution is used. Physics callbacks execute load/destroy and drawing-mask
operations, primary slot zero and secondary slots one through three, quaternion
channels, single-node visibility, absent joint defaults, both bulk-transform
dirty modes, nonfinite transform no-op, and world-position output publication.
Transform fields are compared with actual HSD setters on an independent graph.
Matrix visits must end their reservations without changing the main heap.

A third Item deliberately borrows another Item's secondary pointer: its real VM
world-position call rejects the unregistered graph, preserves the output result,
faults that actor and leaves no active claim. Destroy/reload invalidates the old
captured slot even when graph storage can be reused. Source negatives reject
slots, unknown/numeric root names, malformed paths, writable namespace misuse,
transform Bool mismatch, and malformed/duplicate/reserved root declarations;
the previous accepted bank stays valid and published.

The fixture directly compiles the changed production units beside built native
libraries. Existing catalog zero-tail aggregate initializers require the same
missing-field warning suppression used by production; other strict warnings
remain enabled. Controlled Item userdata initialization attaches an actual owned
primary HSD graph; its cleanup calls actual model destruction/actor detachment.
Runtime and heap kernels are compiled unchanged in the test translation unit to
populate their private transition tables. This is not native Item_CreateAuthored,
Item_OnUserDataRemove, actual secondary draw-hook execution or page replay proof.
