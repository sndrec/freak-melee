# Taunt entry and target controller colors

This hidden console fixture executes the real source compiler/catalog, VM,
Fighter and Item actors, scoped receivers and fixed GObj pool. Owned package,
motion and animation tables are controlled fixture data. No game or retail DAT
construction is claimed.

The actual `ftCo_800DEAE8` body is shared by the reference and VM routes. Motion
installation is a recording leaf that checks native flags/frame/rate and can
retire the caller. The primitive clears `allow_interrupt`, selects the left
motion only for facing exactly -1 and a nonzero left animation x8, and otherwise
selects the right motion. It does not start animation commands. Both motion IDs
and the left animation index must belong to the exact owned tables before entry.

Controller colors call the actual `ftLib_800870BC` body. All 256 controller
selectors are compared through direct binding, Fighter VM and Item VM paths.
The Item paths exercise both the scalar `item.current_owner` handle via the
actual Article motion/property backend and retained `current_owner`, exported
as a guarded engine Object token. Object queries do not reacquire its owner.
Indices 1-4 select native
common colors; missing target, absent common data or other indices produce false
and packed zero. Stale/malformed Object tokens fault without publishing outputs.
RGBA packs to signed I32 with all 32 bits preserved.

Existing position/airborne queries retain their native comparisons and mutation
barriers. Guard observation intentionally injects physical/native retirement;
pure field queries do not inherently invoke callbacks. All unrelated engine
operations are unavailable, including other state continuations.
Float targets/motions, wrong arity and Article taunt entry fail source compilation
without replacing the accepted bank.

Run `run.py --compiler <MSVC-target clang.exe> --output <fresh A: directory>`.
Every subprocess is hidden; no global build, user project or gameplay is touched.
