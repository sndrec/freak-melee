# Generic follower foundation console receipt

This namespace exercises the generic SDK72 foundation while preserving the
immutable SDK71 proposal in `tests/native/cpu_follower_policy`. Production
callbacks replace mode/output decisions when handled; scripts explicitly own
source selection, follower eligibility, destinations, smoothing, special entry
and recovery locks. No native Nana/Popo decision handler is exposed to scripts.
The native fallback remains for absent or healthy-false optional hooks.

## Reproduce

```powershell
python tests/native/cpu_follower_foundation/run.py --snapshot .local/baseline71 --output A:/FreakMelee-test-archives/cpu-follower72-reproduction
```

The runner checks original source/compiler against71's immutable manifest,
extracts actual typed definitions, builds the full live compiler once, generates
both routes and compiles/runs the coherent source/module matrices. `--compiler-test`
can use root's coordinated compiler fixture instead. Live headers and consumed
compiler/source inputs are individually hashed in the receipt; this is not a
claim that live72 corresponds to immutable71. There is no game or installation.

CMake recipe: compiler.c plus `${NATIVE_FIGHTER_SCRIPT_SOURCES}` and actual
`native_fighter_parameters.c`; invoke compiler executable with two filenames,
`follower_action.inc follower_callback.inc`. Compile module.c twice with
`FOLLOWER_MODULE="follower_action.inc"` / `"follower_callback.inc"`, include the
output directory, src and Dolphin headers, `MELEE_NATIVE=1`. Root owns CMake.
The source runner is separately reproducible console evidence.

## Boundaries

- history_test.c links the real new history implementation and compares original
  frozen71 B0918/inlineM0 for defined positive-axis conversions, wrapping both
  independent cursors, retained bytes and direct trigger truncation. Signed
  negative axes are separately tested authored behavior, never counted as
  original-C pairs. Registry membership/receiver lifetime are controlled.
- source_test.c runs the complete actual B3900 body and actual old/new common
  destination latch. The five called phase internals are explicit controlled
  boundaries. PAGE_NOACCESS, reuse, userdata, kind/data and Definition replacement
  must stop before the next phase and elapsed-frame increment.
- hook_test.c executes the complete actual old/new B2AFC and B0AF4 bodies and
  current full B683C. Mode/output absent and healthy-false paths compare CPU state
  and ordered calls; floor hit/miss both run. Mode6 native default calls are
  recorded boundaries, not a delegated authored follower implementation.
  Combat/recovery handlers, cached enemy selection, stage responses, original
  SpecialLw entry and RNG are controlled. Capture callbacks test both results
  with source or victim retirement, reuse, changed link/userdata and source
  kind/data/Definition. Ordinary pummel continuation remains the original body.
- backend_test.c executes actual bounded stage queries, actual old/new common
  island-hazard body, actual common hazard-item/height helpers and actual target
  getters. Stage dynamic collision/item conditions and live registry are
  controlled. It proves invalid lines do not reach raw island/exclusion lookup,
  not full physical stage simulation. Full-width IDs and absent/null targets
  preserve vector outputs and return scalar defaults.
- module.c invokes actual generated callbacks from both routes, including nested
  effectful arguments, all query/plan Host operations, atomic output failure,
  strict/ranged writes, missing Host rejection and PAGE_NOACCESS/recycled source
  continuation. Host implementations are deliberately controlled retirement
  boundaries; no engine solver is mocked as an authored move.

`refactor_sites.json` inventories89 ordered renamed-operation callsites across36
actual original functions. Seven removed forwarding/duplicate definitions are
explicitly listed. The former forwarding follow function now contains the real
follow computation; its common preparation body is split substantively and
called directly. A lexical native/non-native duplicate recovery-switch brace is
masked solely for extraction accounting, retaining exact source line positions.
No production or frozen source is altered by extraction.

The full-body gate detected six dropped callsites during initial forwarder
removal (five B2AFC destination calls and one B2790 recovery call). All were
restored to direct substantive operations, and callsite/order inventory now
passes. Historical first..seventh receipts remain under A archives. The
compiler's initial negative integer literal1 was corrected to1.5 after verifying
existing numeric typing; no language exception was added. Fixture definition
extraction now requires typed definitions, excluding earlier callsite matches.
