# Source-owned animated aerial jump

The fixture uses real source compilation, program preparation, Fighter actor,
Execution/VM, catalog/Jump/Setup/AirPhysics dispatch, native fixed GObj/Fighter
pools and actor snapshots. The owned package facts/data and native motion/audio
leaves are controlled. Actual Begin, drift and adjusted TransN kernel bodies
are mechanically extracted from current source. The Kinetics invocation switch
is mechanically narrowed to its exact air_accel_normal case; other operations
remain unavailable.

Sound-stage instrumentation observes the old motion phase before the late
animation hook installation. Nested VM fault/free instrumentation is an explicit
continuation test, not a claim that native audio itself invokes authored code.
Snapshot tests restore actual actor records against live native Fighter/GObj
peers, whose native callback fields remain unchanged during those cases.
No retail animation, imported DAT/package, renderer, whole scene rollback or
gameplay acceptance is claimed.

The grouped cases cover missing-hook rejection before mutation, false/true
entry and late code-ID installation, exact native drift/TransN+bunny math,
retirement and VM faults at all four entry stages, helper replacement/clear,
motion reselection, NewLife and snapshot hook-slot validation/restoration.

Run tests/native/script_animation_jump_fixture.py with --compiler and a fresh
--output directory on A:. All child processes remain hidden.
