# Secondary model scene owner

Private runner uses the current built native libraries, actual compiler,
program preparation/publication, Item actor/storage/VM, GObj lifetime, package
leases, main HSD heap allocation, model pool, graph construction/destruction,
ID mapping and matrix traversal. No production function is substituted.

The fixture explicitly stages a candidate with real owned Link DAT imports and
a typed Arrow secondary-root table imported by actual `model_root` source
metadata before publication. It compiles minimal Article animation bodies and
executes them through the real VM. Actual runtime/heap source units are compiled
in the fixture translation unit so their private transition tables can receive
explicit setup inputs; their getters/allocator functions stay unchanged. This
does not prove Workshop/loading, actual Item factory physics or gameplay.

Cases cover no-root/no-allocation prepare, an actual package lease, exact
published Item identity distinct from Fighter identity, invalid ordinals/slots,
independent duplicate roots and replacement, bounded lazy matrix allocations,
balanced/reentry claim checks, live Destroyed observations and mid-claim removal
flag invalidation with balanced cleanup, borrowed-slot rejection, prepared-identity
substitution, actual Destroy/userdata cleanup, scene drain and lease release.
Native duplicate descriptor IDs name the newest graph; removing it does not
restore older mappings. No private state or rendered graph is borrowed.

Userdata setup and the `destroy_item` cleanup callback are controlled; that
callback invokes actual Model_Destroy/Detach, rather than proving the entire
production Item cleanup scheduler. Same-kind duplicate selected rows exercise
the getter's first-match rule, not distinct-kind package/root deduplication.
The scene unit is compiled directly alongside current native libraries, so its
latest source is exercised without rebuilding the shared library in this runner.

The registry/core/backing reside in existing `.mstate`/main-heap snapshot regions
in production. This console fixture does not initialize rollback page history or
prove whole-match restoration, renderer/GPU draw, scheduler hook execution,
secondary metadata/frontend admission or complete Arrow gameplay.

Final private cohort: 80 checks in seven cases, four actual constructed graphs
and two native matrix visits. Evidence is archived at
`A:/FreakMelee-test-archives/source-article-model-scene-oct09-final/receipt.json`.

Primary-descriptor clone cases use the real interpreter binding, HSD graph constructors, scene registry/pool and heap. They check independent root/child addresses, exact copied rotation, uniform Item scale, descriptor translation, vacant/occupied behavior, VM signal dispatch, generation retirement and unchanged main-heap free bytes during construction/matrices/destruction. Primary setup and Item userdata initialization remain controlled transition inputs.

The shared runner optionally accepts `--fox` and `--falco` freshly cloned drafts, exercising each actual stock trail descriptor through minimal owned Article scripts and the same pool/clone path. Link additionally fills the 128-instance scene budget, checks rejection of the next vacant slot and successful replacement at capacity, then destroys every graph with unchanged main-heap free bytes. These are model/ownership checks, not full specials or rendered fighter acceptance.
