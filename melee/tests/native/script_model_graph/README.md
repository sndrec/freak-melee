# Source reserved-model-part installation

The grouped hidden console executes the actual catalog/compiler, property and
call dispatch, Fighter actor/storage/VM, lifetime/pool code and source-owned
`nativeFighterModelGraph_Install`. Actual `ftParts_800753D4` supplies the native
two-pose comparison, with unchanged insertion and preorder iterator bodies.

HSD graph allocation and part registration are controlled leaves: they preserve
descriptor transform/drawing data, reject unexpected graph trees and expose
allocation failure, cleanup, insertion order, native append and registration.
The original/native comparison covers four insertion modes and four descriptor
selections including root sentinel255. The interpreter then compares the same
owned reserved-part result through actual compiled helper execution. Duplicate,
missing/index/placement, allocation and drawing-capacity failures preserve the
native Bool result. Wrong ABI and source/asset admission errors withhold output.

Retained-source and table/rig negatives use an explicit observer at completion
of the actual installer body, after its cached Fighter writes. This is test
instrumentation for publication guards, not a claim that native installation
contains an authored callback. The production installer is unchanged. Scene
heap allocation, class constructors/material registration and DAT publication
are not exercised as whole runtime loading. Package asset metadata and fixed
Fighter payloads are controlled. There is no renderer, game launch or audio.
