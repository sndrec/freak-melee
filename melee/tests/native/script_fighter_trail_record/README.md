# Fighter trail output record cohort

This isolated console uses actual source parsing, parameter preparation, bytecode,
Execution, Fighter preparation/publication/actor dispatch, event output records,
receiver scopes and GObj fixed pools. Canonical Link and Young Link `on trail`
bodies are extracted unchanged; named immutable parameter values are supplied
from controlled native `ftLk_DatAttrs` sword fields. All fourteen output fields and
the raw bone anchor are compared with the actual stock afterimage reader.

The same actual reader tests source-owned rig/class admission, missing hooks,
invalid trail values and faulted actors. Execution and Fighter calls must preserve
native output records on error, retirement and malformed record IO. Failure injection
occurs in a controlled pure observation leaf; it never supplies trail results.
The raw Execution lifetime provider checks native link/generation and Fighter
back-reference. A classifier-only substitution is instead rejected by the actual
afterimage reader's retained `NativeFighterLifetime`; it is not claimed as VM
retirement. The cohort also verifies no stock/advanced definition query occurs
for missing or faulted source trail hooks.

The selected package, native parameter records and initialized joint class metadata
are controlled. No DAT import, graphics, sword-item path, class bootstrap, full
Link preparation, motion/animation behavior or renderer/game acceptance is claimed.
Unrelated native operations reuse the explicit unavailable scheduler boundary.

Run with `python run.py --compiler PATH_TO_CLANG --output FRESH_A_DIRECTORY`.

The grouped cohort contains 57 cases, including six complete fourteen-field
native/source comparisons. Its call count names explicit Fighter/Execution
invocations; reader-triggered source callbacks are additional actual VM work.
