# Immutable article model layers

This unregistered console fixture exercises the typed layer foundation. It does not compile a fighter module or launch the game.

```powershell
python -B tests/native/article_model_layers/run.py --snapshot .local/baseline60 --output .local/article-model-layers60-reproduction
```

The runner verifies frozen compiler/SDK hashes before and after execution. Only the explicitly migrated adjacent Item/Article headers are overlaid. Production source bodies and their hashes are recorded in each fresh output receipt.

The final receipt is `.local/article-model-layers60-final/receipt.json`: 4,775 checks, zero failures, ten full article imports, 240 draw cases and nine invalid-import cases. All ten actual USA v1.02 `PlGw.dat` records are decoded with the complete common article importer using its existing generic regular/Chef alias routes. The fighter importer’s actual regular/Chef attribute bodies are extracted separately and compared to those owned lists and Chef scalar values; this fixture does not execute the complete fighter importer or load Kirby’s separate archive. Lists are copied into the import arena, preserve their order and repetitions, and have distinct ownership across imports.

Synthetic inputs exercise 256-entry lists and 100-node graphs, repeated/unsorted indices, over-capacity counts/graphs, cyclic graphs, root/out-of-range indices, invalid pointer/count combinations, wrong descriptor extent, missing root and explicitly empty lists. Empty lists are represented by count zero and a NULL reference for each list; a relocated address zero is a real local DAT target, not a NULL reference.

Actual live-model validation checks the primary graph, listed parents and matching dynamic-bone ordinals. The bind operation enables only the Item’s own Article metadata and disables on failure; explicit disable clears the pointer and flag. The source-phase graph constructor is controlled, while actual HSD subtree Set/ClearFlags bodies execute. The draw matrix executes the complete dispatch and three pass bodies over camera modes 0/1/other, parent-hidden branches and held/displacement combinations. Visibility/pass ordering and restoration are asserted. CE64 executes actual binding, color-query ordering and scale call sites; private Chef/Rescue/native article state is kept outside layer storage.

Actual primary replacement bodies `it_80273318` and `Item_802680CC` execute with controlled HSD object removal/load/install boundaries; the fixture asserts that layer binding is cleared before removing or installing the root. Extra model slots 1..3 do not replace the primary model and retain their existing behavior.

Color getters, diffuse/scale work, HSD allocation, camera/displacement and draw/GX/material sinks are controlled. No rendered pixels, material pipeline, animation engine, allocator lifetime, gameplay or Game & Watch independence acceptance is claimed. Root’s full importer/global semantic tests provide separate integration coverage. The accepted Chef fixture remains immutable and retains its own original SDK; any live consumer of its old three-argument CE64 stub must migrate separately.
