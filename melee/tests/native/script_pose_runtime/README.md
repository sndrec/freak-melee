# Direct native pose operations

```powershell
python tests/native/script_pose_runtime/run.py --compiler A:/FreakMelee-test-archives/baseline72/compiler/clang.exe --output A:/FreakMelee-test-archives/script-pose-runtime-new
```

Use a fresh private A: directory. Compilation and execution are hidden and
bounded. The runner verifies input hashes and writes a receipt. CMake also
registers the routing fixture as `native_script_pose_runtime`.

The fixture executes the production dispatcher, catalog descriptors, source
data/actor guards, physical callback lifetime and generational match pool. It
checks all eight operations across fourteen live/blend destination combinations,
independent finite frame/weight values, raw integral index bounds, graph membership
and 182 retirement/replacement cases. Outputs remain unpublished after failure,
and costume lookup retirement prevents the subsequent copy call.

Selected package/storage/asset views, topology validation and native pose math
are controlled. This fixture does not establish animation interpolation,
imported retail topology, rendering or Sheik gameplay parity. The separate
metadata/catalog suites cover typed source-to-bytecode/VM behavior; ordinary
source-check additionally verifies real owned asset import and candidate
preparation. Read the checkpoint before treating those combined results as a
complete fighter migration.
