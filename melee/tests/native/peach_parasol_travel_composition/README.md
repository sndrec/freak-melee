## Boundaries and judgments

The extractor pins body/file hashes and verifies the preserved original54
lifecycle manifest. It requires actual definition prefixes; column-zero function
terminators handle original preprocessor alternatives with two textual opening
switch braces.

Motion/animation internals, animation-motion physics, quick deceleration, 831CC
geometry, freefall/landing/open interiors, item animation/audio/removal,
visibility/pause and recipient lookup are controlled boundaries with ordered
traces/state effects. Actual common Fall math, ftCheckThrowB3 inline, selected
original decision bodies, generated callbacks and production generation-aware
callback lifetime execute. Constructor/allocation/HSD graph/rendering/scenes/
rollback are outside this fixture. Common144/146 callback identities are checked;
root's separate held entry/lifecycle fixtures cover their interiors/caller guards.

Original tilt uses unsuffixed double 1.0; authored math uses Float expressions.
The healthy raw-DAT matrix measures zero difference; arbitrary changed tuning
is not claimed bitwise equivalent. Inactive special-union request bytes alias
landing fields, so the fixture compares surviving semantics, not that dead data.

NULL-held landing expiration dereferences undefined native memory. It is excluded
from healthy pairs and separately tested as safe retention. Unsupported native
requests index invalid/null table entries; authored requests refuse without
mutation. Entry/item-transition/nested-recipient removal or recycling stops
continuations through actual production lifetime checks. No production source
fix or native undefined-behavior emulation was introduced.

Historical travel_existing.fms, frozen50 source_inventory.json,
proposal_sources.json and generic_contract_proposal.md preserve initial planning;
they are not generation inputs. SDK55 supplies the required generic interfaces.
Earlier pluck/counter/Turnip/Float/SideB matrices are reused unchanged, not counted
as reruns. No new shared API is needed for this supported travel/held slice.
Full activation, constructor/render ownership and gameplay remain gates.
