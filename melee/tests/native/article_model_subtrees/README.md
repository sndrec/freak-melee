# Article model animation paths

This console gate compiles the current candidate compiler and both actual
generated module routes, then executes complete extracted production model
animation routing bodies. It does not use a frozen SDK claim for live headers.
The supplied compiler binary and every compiler/source/header input are hashed
and checked again after execution.

```powershell
python tests/native/article_model_subtrees/run.py `
  --compiler .local/baseline72/compiler/clang.exe `
  --output A:/FreakMelee-test-archives/article-model-subtrees-root
```

Use a fresh A-drive output directory. All subprocesses are hidden; compilation
selects VC tools 14.44. No global build, game, package or installation runs.

The existing `article_animation_components_compiler_test.c` remains the actual
compiler driver. Its direct/bundle/scattered/indexed metadata assertions are
preserved. New root/path syntax and malformed paths are checked through full
generation. Both generated module routes execute ordered Add/Request/Advance/
Remove calls at the primary root and its first child, inspect the Add Bool
result, and stop at six synchronous source retirement boundaries. Retired item
storage is PAGE_NOACCESS; the registry boundary rejects the retired identity
before reading it. The Bool assignment is checked before the subsequent branch
or state write. A controlled false Add result takes the authored failure branch.

`test.c` executes the complete actual `model_root`, `nativeModelJoint_Resolve`
and four `nativeArticleModel_*Animation` bodies. Its sixteen valid cases select
root, first child, second child and grandchild for primary model 0 and additional
models 1–3. It verifies selected pointers, exactly one shared HSD operation per
call, graph arguments, operation order, explicit empty bundles, missing paths,
models/articles/names, and non-finite requested frames. HSD animation functions
are observed sinks here, so this gate establishes routing and validation rather
than evaluating animation channels or rendering pixels.

The actual HSD evaluation gate is the existing `native_model_runtime` target.
`article_model_test.c` now directly passes the new path argument in every call
and additionally installs, requests, advances and removes a child-only animation
with the real HSD functions, checking the root AObj remains absent and the child
frame matches direct HSD evaluation. Root runs that target in its coordinated
matching build; this scoped runner does not silently link an old runtime library.
