# Jab restart continuation

```powershell
python tests/native/jab_restart_continuation/run.py --root . --original-sdk .local/baseline58/sdk --compiler .local/baseline58/compiler/clang.exe --output .local/jab-restart-current-source
```

This mechanically extracts immutable SDK58 and candidate `doAttack12` and
`doAttack13`, renaming only their own identifiers. It directly imports the
accepted source extractor (its hash is an input), without changing that
namespace. Real `native_callback_lifetime.c` registry checks are linked.

Healthy pairs cover both policy results, absent Definition, present Definition
with an absent policy, pickup outcome and
Mario/Marth/Pikachu/Pichu raw routing across four full-width generations.
Current-source safety cases keep true/false result branches separate and remove
or recycle the source, change kind or Definition, or clear source userdata from
the callback. Every invalidation must stop before common entry/pickup/motion
continuation and preserve untouched attack flags. Source absence is tested
with both an empty fighter registry and a null registry.

Common jab and Attack12 normal/rapid entries, pickup and motion publication are
controlled dependencies. This is a focused continuation contract, not repeated
full common-entry startup proof (the accepted normal_attack_contracts namespace
covers that separately). Initial engine dispatch requires readable Fighter
userdata: absence cases preserve it while unregistering the source. No null or
poisoned initial-pointer safety claim is made. Old bodies are never run after
callback invalidation; no union bytes, object addresses or padding are compared.

Fresh `result.json` records input/output/source-body hashes, commands and exact
counts. No production changes, global build, installed package or game run.

Final live-source comparison passes 384 original/current pairs, 5,892 checks
and 84 separate source safety cases. Source safety is tested for true and false
returns across all four generations; invalidations have no following entry,
pickup or motion event.
