# Owned source declarations

The accepted run passed 404 checks across 69 cases and four real stock DAT imports: Peach, Game & Watch, Popo and Nana. Independently copied FMA facts supply roots, motion extents and rig bounds. The fixture runs the actual SourcePackage importer, compiler and Fighter preparation on separate minimal authored programs; it never uses a dummy behavior Definition or successful metadata stub.

Root sound/friction/visibility recipes become candidate-owned facts before DAT import. Missing recipes preserve copied facts. A declared sound remap/KO table replaces the complete prior routing table, preserving native rule order, costume masks and mapped Int32 bounds. Mute and friction declarations are unique; KO masks cannot overlap. Visibility bits are bounded and require an actual imported lookup and costume graph. An absent Game & Watch slot fails the real importer rather than producing an invented lookup.

The Ice Climbers checks prove that copied clone facts alone do not contain their authored friction exemption or sound routing/KO table. Both recipe-normalized packages preserve those values, and native sound-policy functions produce the original forward/reverse ID mapping. Root and numeric motion fields remain unchanged.

Rejected recipe syntax, bounds, duplicates and layout mismatches leave candidate output and accepted packages unchanged. Obsolete base directives still reject. Common motion policies now apply actual canonical animation/interrupt/physics/collision phases to owned rows; authored phases prepare explicit overrides. Numeric asset fields stay unchanged, row tampering rejects revalidation, and invalid/duplicate policies publish no partial row changes.

This is immutable data and minimal source preparation proof, not complete Peach/GW/Climber behavior, whole-match phase execution, paired activation, rendering or game acceptance. Original files remain untouched. The hidden runner writes copied projects and fingerprints to a fresh A: archive; CTest creates a fresh UUID archive per run.
