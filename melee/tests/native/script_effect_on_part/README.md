# Raw-part effects

This hidden console cohort tests the canonical `effects.spawn_on_part(effect, part)` operation through actual source parsing, statements, bytecode and VM. It addresses a signed raw rig index; it does not map a semantic bone role or queue an async effect. An absent slot is a healthy no-op after admission of the live owned rig. Unsupported effect argument ABIs remain errors before native work.

The native comparison pins the original shared raw-part helper, exact efSync `0x4EC` case, actual generator attach/refcount body and actual class ancestry. Generator allocation/resource lookup is controlled and fixed. Selected package/program/storage and actor views are also controlled; the real pool and physical/source-layout guards execute. This is not a real actor scheduler, complete paired package, renderer or game acceptance claim.

The grouped cases cover raw/semantic mapping disagreement, synchronous timing, native allocation absence, absent slots, exact integral IDs, malformed types, source/program/storage/rig/class retirement and pool reuse. Native side effects already completed remain completed if output is withheld after retirement. A source VM lifetime-negative confirms no subsequent effect statement executes.
