# Companion Sleep continuations

This isolated silent console executes the source-exact BFD04/BFD9C/D4F24 (and its inline)/D331C/ftLib87140 bodies with actual compiler, owned actors, callback VM/storage, GObj and Fighter pools, and NativeFighterLifetime. The obsolete alternate-constructor tail extraction has been removed: complete constructor and Unload coverage belongs to the constructor fixture, while this corpus retains Sleep/death continuation coverage.

Motion installation is a controlled leaf that installs Sleep and dispatches the actual bound StateChange callback. Camera payloads, effect argument capture, status, sound-reset and unrelated cleanup are controlled; no devices or render resources open. A successful ProcessDeath boundary establishes a new generation; the complete native reset is outside this proof. The authored callback command write is an explicit test probe for actual pool retirement/reuse or exact source identity mutation. It does not suggest the native command setter normally contains callbacks.

The corpus distinguishes independent peer retirement (healthy primary status continues) from primary retirement, fault, generation/layout change and physical GObj/Fighter slot reuse (cached tails stop). Healthy foreign callback behavior remains native. The explicit immutable-layout corruption probe can finish D331C cleanup because that existing body checks callback return and physical generation; the new exact outer guard then suppresses Sleep/ftLib continuation. This does not undo completed cleanup or claim that D331C contains arbitrary metadata corruption.

Pool payloads satisfy the engine userdata invariant; arbitrary forged userdata pointers are not tested.

## Guard order and proof scope

BFD04 captures before motion change and checks before cached invisibility/camera writes. BFD9C retains the primary through its own Sleep and again through the peer's death/Sleep; a lost or faulted peer alone does not suppress the healthy primary's status call. D4F24 validates after D331C before its inline flags and Sleep. ftLib87140 validates before its cached rumble tail, then captures the successful new life after ProcessDeath resets generation. Constructor ownership and failure unwinding are verified separately.

Healthy owned and foreign bodies preserve the native ordering and Sleep field effects; disabled retirement, missing peer, self peer, omitted effect index and already-asleep early return are covered. Destructive probes assert that both actual GObj and Fighter pool addresses are reused while cached continuation still stops. Real divide-by-zero VM faults require no simulated fault status.

Full production translation-unit syntax is checked; the two pre-existing fighter.c unused `!fp` expressions remain warnings. Fixture code is Wall/Wextra/Werror clean except the source-identical native D4F24 stack pad, suppressed only around the extracted native bodies.
