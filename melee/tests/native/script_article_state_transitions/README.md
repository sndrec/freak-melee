# Article state transitions

The actual source frontend, catalog, VM, Item actor, storage, receiver scopes and
fixed GObj pool execute `item.change_state` and `item.change_state_flags`.
The actual `Item_80268E5C` body is compared with direct native state transitions;
selected immutable specs and animation/model/audio/geometry leaves are controlled.
Nested state changes, callback reset ordering and invalidation cases retain actual
actor identity. This does not prove DAT import, rendering, or complete Sheik.

The cohort compares all 512 combinations of defined native state flag bits,
plus the default animation-update form and a full unsigned flag word. Real
authored callbacks exercise the two calls and refreshed phase selection. Native
flush/animation leaves inject nested transitions, faults, logical retirement,
model/schema/program/class substitution and actual GObj destruction/reuse.
Normal owner mutation remains valid; immediate and deferred removal terminate
VM continuation. Invalid direct payload/state/revision admission preserves output.

Specs/state tables are manually pinned fixture inputs, not successful stubs for
the Item actor or VM. Graphics/audio/animation kernels and immutable asset
selection are controlled. Nested callback and fault injections execute the real
actor; unselected factory/Fighter families explicitly reject or abort. This
compares native field/order behavior without native animation controllers or
model loading. Corpus model-less descriptors remain supported through a native
anchor JObj; a NULL live Item JObj is invalid for the native state operation.

`run.py --compiler A:/path/clang.exe --output A:/fresh/private/directory` builds
and runs hidden consoles only. It records commands, warnings, results and hashes
of the actual/extracted inputs, compiler, headers and scope documents. Owned
test/backend units have warnings-as-errors syntax checks; existing SDK array
declaration/native signed-count warning exceptions are explicit.
