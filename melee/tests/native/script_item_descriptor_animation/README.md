# Native Article descriptor animation proof

This grouped fixture imports the same owned Link and Young Link draft assets
used by the earlier model-animation cohort. It compiles and prepares actual
Article source, publishes the immutable program and descriptor-demand pool,
attaches actual Item actors, executes the real VM, constructs real HSD graphs,
and uses the fixed native AObj/FObj pools. Both Boomerang and Bomb imported
state tables are selected independently of the fixture's authored state count.
Every entry's Set/Add admission and uncovered flags are recorded explicitly.
The admitted subset is compared against the native kernels; uncovered entries
must diagnose without publishing the descriptor or altering the graph.

The first Bomb probe exposed that descriptor 0 (and the retained source's
selected descriptor 3) was unsupported, because `HSD_A_T_TIMG` directly converts
the controller float to an image-table index. Descriptor 2 alone was sparse and
admitted; that did not prove the retained Bomb call. The generic correction
covers complete bounded CON-only streams, native truncation in `(-1, count)`,
and exact imported borrowed image tables. Bomb descriptors 0/1 contain a
five-byte 0/1 stream, descriptor 3 a 78-byte 0/1 fast-fuse stream; each selects a
two-image table. The genuine corpus installs 0 then 1 as separate initial
histories, runs their native image switches, removes animation while retaining
the table/image, installs selected 3, and compares further native switches.
Selected-image pointers join the controller/track graph comparison. Replaced
tables/images, nonfinite or out-of-range live indices, and unsupported
interpolation are refused. No general spline/linear image-index range proof is
claimed.

The oracle assigns the same native descriptor and calls unchanged
`Item_80268D34` (Set) or `HSD_JObjAddAnimAll` (Add). Joint, material and texture
controller/track state and transforms are compared after the connected VM call.
The native commands, motion state, actor state revision and Item animation-frame
field must survive both descriptor operations. Explicit advancement is compared
separately. Missing/negative/extreme indices preserve native no-op behavior.

A separately labeled synthetic root-sibling model proves the Set traversal
requires three controllers while Add requires two and retains the sibling
controller. Its controlled descriptors replace the candidate asset row before
preparation/publication; they are not retail model evidence.

Coverage includes dynamic-bone subtree skips, fixed controller/track pool
exhaustion and allocation-generation exhaustion, foreign controller origins,
end-callback/reentry context, malformed shadow/dynamic extents, exact Int
compiler/backend admission and transition preparation with unused modelless
owners. Regions_Build and Pages execute, restore and replay three actual
VM/controller frames, retaining Item userdata and native controllers.

Texture descriptor IDs are not necessarily live resource IDs. Each owner run
compares 256 bounded synthetic descriptor plans with actual
`HSD_TObjAssignResources`, including ordinary slot limits and last bump/toon
ordering. A separate synthetic 2/7/2 raw-ID case proves that effective IDs 0/1/2
attach one actual controller/track and produce one matching origin, instead of
two raw-ID matches. Active external material shadow/toon context and cyclic chains
are rejected. These are synthetic boundary inputs, not claims about retail
resource layouts.

The fixture directly supplies unpublished candidate/runtime tables and
initializes captured heap Item userdata. It does not run the production package
loader, Item factory, scheduler or scene startup. It uses actual imported model
construction and animation kernels; the controlled dynamic-bone skeleton points
to the constructed first-child subtree. An additional 64-seed root/first-child corpus compares three authored
`random.float()` calls plus joint-world-position/spawn-at-position against
actual `it_80278800` with zero offset and jitter. It compares the native RNG
state and effect parent/XYZ; the actual `lb_8000B1CC` root translation and child
matrix branches run. `efSync_Spawn` is an explicit silent argument sink and its
unused model-recipe leaf aborts. This proves forwarding/RNG, not particle,
model allocation or rendering. The controlled native bone table installs only
the two indices visited by this corpus. No GPU, sound device or game is opened.
No arbitrary callback, shader, shape, palette or asset-pointer safety is claimed.
Descriptor arenas and immutable native state tables remain pinned trusted imports.
The Pages proof covers this cohort, not whole-match rollback acceptance.

The runner requires a fresh private A: directory. It snapshots and hashes actual
source/header files, runtime link inputs, owner assets, compiler and fixture
inputs, uses hidden processes, and rehashes copied/live inputs before issuing a
receipt. Its production units include the descriptor runtime/preparation,
program publication and unchanged Item animation kernel; the renderer and audio
libraries are linked dependencies only. Built-in scene/runtime/heap sources
expose controlled transition input storage. Their unused static functions and a
known SDK array-parameter warning are the only suppressed warning categories.
