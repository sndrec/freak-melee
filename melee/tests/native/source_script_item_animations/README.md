# Connected source Item animation cohort

This private cohort compiles and publishes genuine Boomerang `model_root` and
`model_animation` declarations for both Link and Young Link. One bundle uses
explicit `joint 76 material None shape None` components, while the other retains
the consecutive-pointer shorthand. It executes
add/request/advance/remove/rate through the real Item actor and VM, comparing
primary and independent secondary graphs against native HSD/lb operations.
The selected root is excluded by the actual native rate walker. The sparse Add
test applies real trail bundle 76 to the actual primary graph root and child;
this is a synthetic animation application, not retail Boomerang behavior. No
primary descriptor/graph is replaced. It checks native retention of controllers
on omitted descendants. Bundle 76 has no root controller and one child
controller: applying it at the primary child and then root retains controllers
at depths two and one. The rate case selects the real animated secondary child
to verify root exclusion. Separate genuine primary-only sources declare no
roots/bundles; their four animation selectors still require a valid scene
package lease. Native primary state descriptors remain in the prepared origin
ledger even when the source declares no animation bundles.

The fixture directly initializes unpublished candidate/runtime/main-heap tables
and Item userdata. These are controlled transition inputs, not substituted
runtime functions. Cleanup calls real model Destroy and actor Detach, rather
than claiming production Item constructor/destructor or scheduler coverage.
No GPU, audio or game process runs.

Grouped coverage includes literal owner/name/model/path compiler
rejection, absent/vacant defaults, finite frame/rate validation, retained
controller provenance, global callback admission, actual fixed AObj/FObj pool
exhaustion and generation rejection without replacing the old graph, and native
graph equality. Actual Regions_Build and Windows Pages restore/replay captures
heap Item userdata, actors, scene registry/graphs and animation pool backing.
This is a bounded animation cohort, not whole-match rollback.

Run after production freezes and libraries are rebuilt:
`run.py --compiler CLANG --link LINK_DRAFT --young-link YOUNG_DRAFT --output FRESH_A_DIRECTORY`.
The runner copies sources, libraries and owned assets privately, invokes no
shared build, and records both copied and live input fingerprints.

Frozen review8 receipt:
`A:/FreakMelee-test-archives/source-script-item-animations-oct09-review8/receipt.json`.
Both full owner runs pass 1,465 checks / 48 cases / 110 native graph comparisons,
with eight executed frames and two actual Pages restores each. Both primary-only
runs pass 129 checks / four cases / 12 native comparisons each; each retains
eight origins from native primary state descriptors, with no source roots or
bundles and four selectors. Aggregate: 3,188 checks, 104 cases, 244 native graph
comparisons, 16 executed frames and four restores. Copied and live fingerprints
remain unchanged in that receipt. This final result paragraph was added after
that run; no code or runner input changed.

Earlier failures distinguished fixture assumptions from real implementation
bugs: source states needed all four declared bodies; published origin arrays
rebase during publication, exposing a scene pointer-equality bug fixed by the
owner; retail bundle 76 animates its child rather than root; and the history
runner needed the production zero-initialized section compiler flag. No native
ownership/provenance guard was weakened to make these cases pass.

## Vector and collision-normal batch

The shared fixture now compares all three axis rotations against `lbVector_Rotate`
for raw Fighters, owned Fighters and owned Items, rejects invalid axes without
publishing outputs, and reads all ceiling/wall components including signed-zero
and nonfinite bit patterns. Each Fighter role also compares unit-axis velocity
rotation against `lbVector_RotateAboutUnitAxis`. The actual owned Fighter helper
exercises typed Float outputs and surface reads through the interpreter.

2,691 checks / nine cases. The existing 244 aggregate animation graph comparisons,
16 frames and four Pages restores remain intact. No live Ness gameplay or
renderer acceptance is implied. The Item context explicitly carries the current
