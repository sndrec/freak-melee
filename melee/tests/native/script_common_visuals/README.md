# Generic owned Fighter visuals/color contracts

Material-frame requests and material-animation initialization compare against
the shared native group helpers across four channels, including the secondary
draw list. Request/evaluation leaves record exact operation order and frame
arguments; actual native AObj rate statements freeze animations. Missing
channels, draw nodes and animation nodes preserve native behavior. Malformed
selectors/imported tables and inconsistent lengths are rejected before any
evaluation or rate writes. Lifetime, actor status, rig/schema, draw-list and
material/animation replacement are injected after request and after evaluation;
continuations stop and results remain unpublished. Material evaluation and
renderer output are controlled; this fixture does not animate pixels.

```powershell
python tests/native/script_common_visuals/run.py --compiler A:/FreakMelee-test-archives/baseline72/compiler/clang.exe --output A:/FreakMelee-test-archives/script-common-visuals-review
```

Fresh A: archive only; hidden compiler/console subprocesses, strict Werror and
input fingerprints. No game/global build, template or user-project edits.

The actual binding links current ownership guards/catalog extraction and actual
match-pool/physical callback lifetime checks. Exact selected package, actor view,
storage and rig relationships are controlled inputs checked by those guards.
Native ftParts_80074A4C/74B0C/74D7C/74A8C, current/previous queries,
HSD_DObjSetFlags, ftCo_800BFFD0 and lb_800144C8 statements are extracted
from current production source. Healthy operations compare complete Fighter
results against those same shared native primitives, including color priority
refusal; public color.start still returns Void.

set_visible writes invisible=!input. set_group writes prev/dirty only, without
forcing immediate visibility evaluation. prev/idx are signed8, so -1 hides all
and valid alternatives are 0..127. Values are never clamped/truncated. Each group
must exist in the owned model; a nonnegative alternative must occur in at least
one active owned lookup. A channel lacking that alternative still hides its
variants, as the native loop does. Model-variant lookup uses native fallback0,
and outline channels require a declared owned visibility asset. Imported pointer
spans and alternatives are checked before mutation.

set_current_group writes idx while retaining prev. On a changed value it marks
the Fighter dirty and invalidates channel0 with the actual shared 74D7C routine;
an identical value leaves dirty/cleared state untouched. The fixture compares
complete Fighter storage and real DObj flags against these native statements,
including saved-selection reset, every permitted signed8 selection, and both
cleared states. All channel0 alternatives that the invalidator can traverse have
bounded imported TempS/ordinal spans and current DObj-list bounds. A null DObj
entry remains the native SetFlags no-op; it is not an invalid ordinal.

current_group/previous_group return the actual stored signed8 selection. They
are pure integral queries; a wide, negative or out-of-range index returns -1
without low-bit wrapping, as does an empty owned group table. A hidden -1 and
other stored selections need not identify an active alternative for a query.
Float inputs reject. Owned recipient graph/program/table guards apply without
requiring equality to a caller's program, matching existing receiver projection.

Color IDs use 123 common and 6 special entries, 0..128. The selected overlay's
current index is validated before the native priority helper reads it. Both mode
values and priority accepted/refused routes are compared with actual native
statements. Common table data are controlled fixture inputs, not a DAT import.

The original selector/color primitives do not run script callbacks today. Test
injection occurs only after their original statements, immediately before return,
to exercise physical/logical retirement, fault, root/schema/table replacement
continuation guards. No synthetic successful native behavior replaces the source
comparisons. Native pose/visual mutation can already have occurred on retirement;
only output publication and continuation stop. Invalid input/schema cases are
atomic and leave the complete Fighter unchanged. VM/catalog marshalling and full
render/color playback are separate acceptance; this fixture claims none of them.

Final scoped result: 17,249 checks and 2,245 complete-Fighter native comparisons,
including 544 current setter comparisons and 774 native query comparisons.
These include declared outline lookup, empty-alternative -1 behavior, complete
channel0 traversal admission, wide query indices, and retained model/import/
lookup/DObj-list identity. Native signed-loop warning suppression is scoped to
the two extracted native loop bodies; historical catalog trailing-zero aggregate
warnings are suppressed without changing their source.

The attack-color cohort adds 20 complete-Fighter comparisons against the actual
`ftCo_800BFFAC` and `lb_80014498` statements. Priority, command pointers and
active flags reset exactly; timers and unrelated overlays remain unchanged.
Argument/context/storage rejection and eleven injected post-native lifetime or
rig mutations withhold output. Those primitive-return injections do not imply
the native clear operation normally calls script code. Current total: 18,184
checks and 2,265 native comparisons. No color-command playback or pixels are
validated here.

The empty/absent-selector cohort compares 72 cases against the actual saved/current
native setters, including complete Fighter bytes and DObj flags. Empty visibility
rows still record selectors; unmatched selectors hide alternatives instead of
faulting. The signed-byte argument limit and owned-table/mesh/lifetime checks
remain. The resulting totals are 18,673 checks, 2,337 complete-Fighter comparisons
and 580 current-setter comparisons. This corrects the startup reset failure found
by connected interpreted Pikachu gameplay; rendering remains outside this fixture.
