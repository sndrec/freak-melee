# Owned bone queries

This hidden direct-source console executes actual compiler, Fighter Prepare/actor/helper, VM, top-level catalog/Presentation and property routing against controlled owned source rig metadata and real Fighter/GObj pools. It checks semantic-to-raw mapping, raw selectors, world positions and both optional-offset spellings. The source first blocker was preceding legacy cue.consume syntax; this cohort does not claim that bone syntax was missing.

Native comparisons pin pre-batch d25ac9faa: lb_8000B1CC, HSD joint matrix construction/setup and SRT/quaternion kernels, Dolphin matrix/vector primitives and class ancestry. Native C_MTXTrans is extracted from the current Aurora implementation and separately hashed (the GameCube source has only its declaration). Actual math executes for independent root joints and parent hierarchies. Fixture graphs and scale storage are preconstructed; asset import/rendering, IK and arbitrary RObj behavior are outside scope. RObj update and class initialization are controlled continuation injection leaves, including real GObj/Fighter pool release and same-address reuse while the fixture-owned static graph remains allocated; native sampling executes, and outputs stay unpublished when rig/program/storage/lifetime admission fails.

No shared build or game is launched. Run with --compiler and a fresh private A: --output; receipt pins actual source, headers, compiler and generated native bodies. No retail Link package or gameplay acceptance is claimed.

The stable-ID group repeats the native matrix comparisons with ID 500000 at
physical joint 2, including role lookup, offsets and local translation. An old
ID moved to an external reservation and a missing ID cannot alias the body
joint. Current fixtures use the production scene arena and pool constructors;
optional grid/class construction, accessory operations and diagnostics retain
explicit controlled boundaries.

The throw-angle group composes two native world-position/offset queries and
Float `atan2` in authored code, using the stock Fox/Falco muzzle/barrel offsets.
Thirty-six comparisons cover three hierarchy/quaternion arrangements, both
facing transforms and varied translation. Native matrix sampling and `atan2f`
provide the expected bits; no `segment_angle` binding or fighter handler is
introduced. This proves the isolated geometry composition, not whole blaster
or rendered-match behavior.

The grouped cohort covers nine actual compiler negatives, 54 bit-exact native world-position comparisons, raw-selector sampling, class/ABI negatives, ten logical/schema continuation mutations and one actual physical GObj/Fighter release/reuse. It makes no old-private-runner acceptance claim: that runner has existing omitted unselected-family dependencies. Parent separately rebuilt and passed the actual CMake presentation regression.

Root-scale cases execute the actual property/catalog/VM and native setter on
the GObj's rendered root. The root is tested both at raw slot zero and a
different slot, independently of the mapped TopN bone. Comparisons include
matrix-dirty policy, negative/zero/nonfinite Float values, and unchanged
gameplay scale. Absent roots, wrong classes/extents, native/scene retirement
and retirement/root replacement during controlled native class admission
leave outputs and joint fields unchanged. This does not establish complete
Yoshi roll or rendered deformation parity.

Raw joint translation runs through the actual compiler/actor/VM, Presentation
dispatcher and native HSD setter. Forty-eight whole-rig comparisons cover four
raw indices, matrix flags, signed zero and native nonfinite Float values.
Invalid widths/types, missing joints/tables and controlled class-admission
retirement fail without publishing an output or changing translation/flags;
negative and out-of-range indices are healthy no-ops. Gameplay position and
scale stay unchanged. This does not establish animation or rendered-pose parity.

The production property router also reads and writes analog-shield and horizontal
tilt input ages. Script execution covers 0 through 254 and preserves adjacent
input slots. Direct malformed/negative/oversized/Float writes are rejected before
narrowing; canonical Bool and in-range unsigned integer writes remain accepted.
This checks storage/routing, not input sampling or a complete guard transition.
