# CPU-inclusive owned Ice Climbers assembly72

This source-only assembler reuses the immutable accepted `ice_climbers_owned_pair`,
Ice/Blizzard, linked and rope components. Both final sources directly declare
`fighter: behavior independent`; this requests independent package construction.
It does not claim normal import, generated-module ownership or gameplay acceptance.
No default, registry, accepted component or engine source is modified here.

## Complete authored source coverage

Each member preserves all96 nonnull custom motion phases341..366. The eight NULL
phase slots for363/366 remain unassigned. Exact stock entry/lifecycle coverage is
checked against `stock_census.json`; Nana retains NULL special_s/air_s/hi/air_hi.
Three authored articles, ordinary fighter variables and typed recipient exports
remain intact. The retained Squall effect branch has no retail constructor/opcode;
no spawn is invented.

The frozen CPU handoff in `ice_climbers_cpu_owned` is merged without modification:
Popo gets capture-decision and pummel-special hooks; Nana gets prepare, initialize,
spacing, stick-step, stick-limit, drop-command, mode-update and output hooks.
Nana retains its direct accepted Blizzard entry and the accepted Blizzard helper
and state dependencies. Its31 Common/Popo enum policy parameters are included.
The fixture-only query helper is excluded. Input hashes are enforced by the
assembler; the independent CPU source receipt is identified in `cpu_inputs.json`.
All fighter state declarations are placed before helpers; no state-capacity change
or private fighter union is used. Source payload bytes are explicitly unaligned,
not a claim about compiled layout.

launching a game. The manifest contains exact input hashes, every custom phase,
stock entry/lifecycle mapping, CPU hook set, typed exports and import declarations.
The baseline72 manifest identifies historical API preparation; the downstream
normal pipeline must use the matching current tool/SDK containing final CPU and
physical materialization changes. It must not compile new fields against old SDKs.

not acceptance evidence. Earlier18-field source-only inventories preceded the CPU
merge. Accepted component receipts and all failed/historical outputs are retained.
Kirby and unrelated fighter transformations are excluded.
