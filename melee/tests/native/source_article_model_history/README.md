# Source secondary graph page history

This private cohort uses production region discovery and Windows page history,
with actual owned Link DAT import, compiler/program publication, Item actors,
scene model registry, reservation bins, HSD graph/ID/matrix kernels and GObj pools.
There is no replacement restore algorithm and no actor snapshot codec restoring
the graph separately.

The fixture stages an unpublished candidate and a typed secondary root table.
Public model metadata and package loading remain blocked/outside this cohort.
The unchanged runtime unit's private publication tables stay in host `.data` as
in production. The unchanged heap and scene units use production `.mstate$m`;
fixture controllers and expected observations stay outside captured state.
Item payloads and reservation backing occupy the actual main HSD heap. A
page-aligned private heap and complete heap range allow the production region
builder to discover all mutable owners and actual OS allocator metadata.

Controlled userdata setup/removal calls actual model destruction and actor
detach. It does not exercise the full native Item constructor/destructor, scene
scheduler hooks, renderer, GPU, audio, public metadata or whole-match rollback.

The runner builds only a private console executable and never launches a game.
All compiled inputs and linked libraries are fingerprinted before/after.

The accepted cohort performs eight completed frame executions, two actual
`nativeRollbackPages_ToFrame` restores and eleven graph constructions/matrix
traversals. It records the complete production region hash plus explicit pool
allocation generations/free counts, registry occupancy, native descriptor ID,
graph/material topology, transforms/lazy scale and typed `visits` state. A
midpoint restore resurrects the original Item/GObj and loaded graph; a baseline
restore recovers the empty registry. Replaying identical operations reproduces
every recorded observation and the complete region hash. Item reuse uses the
actual GObj pool and a third preallocated heap payload, with the old generation
rejected. No manual `memcpy` or snapshot codec writes restored game state.

The production region builder discovers two paged regions and four exact
regions (83,583,012 bytes in this build). Assertions prove inclusion of scene
metadata/backing, GObj pool, Item actors/payloads, HSD class metadata and ID
allocator; fixture controllers and the privately staged package are excluded.
Exact OS allocator/current-heap and GX texture bookkeeping comes from the real
region builder. Package leases stay fixed through frame mutation and history;
scene retirement rejects both active retained history and restored-but-still
initialized history, then drains graphs/backing/leases after actual shutdown.

This is broad page-history acceptance for this controlled source scene, not an
actor-only graph snapshot, arbitrary same-address graph resurrection, public
secondary metadata, or whole-match rollback claim. The real Arrow graph is one
joint; topology comparison covers its DObj/PObj/material/TEV children rather
than claiming arbitrary joint trees. Userdata cleanup is a controlled callback
invoking actual model destruction/actor detach, not `Item_OnUserDataRemove`.

`--frozen` validates and copies the earlier production source/header/library
snapshot; only the current fixture source, runner and README are copied from
the live checkout. Thus later live development cannot silently alter this
cohort. The receipt pins both the parent freeze manifest and final copied
inputs. Included unchanged native units suppress unused function/variable
warnings; the SDK's existing array-parameter declaration mismatch is suppressed.
Other fixture warnings remain errors.
