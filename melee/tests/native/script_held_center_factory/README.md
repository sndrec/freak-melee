# Held-at-center factory

This isolated console links the actual source frontend, prepared factory owner resolver, catalog, bytecode/VM, Fighter and Item actors, storage/receivers and fixed GObj pools. It executes the actual public Item constructor/internal scheduler, Creator capture, Created hook and native pickup wrapper. The actual ECB-center kernels run; extracted stock bomb constructor argument initialization supplies an independent comparison for previous/current position and default fields.

The selected package/facts/program/spec tables are controlled immutable inputs. Article/model import, native model initialization, bone attachment, animation, sound and platform leaves are controlled. Native attachment records the exact raw slot and changes current damage owner; no render or full native attachment geometry claim is made. All callback bodies execute through the real VM. Fault/retirement/payload mutations are injected at their property-write boundary.

The grouped cases cover healthy ordering, missing raw bones, allocation/Spawned NULL outcomes, shared physical kinds with distinct source owners, default actor creation value, normal state/owner/attachment mutations, nested creation, and retained caller/child program/schema/physical/rig identity failures. No game, whole Link source acceptance or DAT/render parity is claimed.

Raw part arguments preserve signed/unsigned native32 representation; actual compiled I64/U64 wide literals reject before allocation. Creation handles preserve all32 bits, including `0x80000000` and the existing `0xffffffff`/`-1` ambiguity. Child identity retention begins after the actual constructor; Created/PickedUp substitution checks do not claim detection of arbitrary model/payload replacement before that capture. Actual failed VM writes exercise Spawned constructor cleanup and later hook errors separately from injected actor fault flags.

Compiler negatives reject physical-kind/parameter selection, conflicting root state, Article caller scope, Float raw slot and incorrect arity. They preserve the compiler acceptance output sentinel, without claiming a full package transaction or immutable program publication proof.

`run.py --compiler PATH_TO_FROZEN_CLANG_DIRECTORY --output FRESH_A_DIRECTORY` creates hidden compiler/console processes. The receipt records exact sources, headers, compiler, commands and immutable input fingerprints.

The connected source declaration uses `It_Kind_Fox_Laser`, a shared numeric
ItemKind constant, with controlled Mario-fire assets. Selection must follow the
prepared declaration semantic rather than treating the runtime literal as a
source-tree index. Out-of-width I32 arguments are still rejected.
