owner units. Hardware PAD calls and replay/profile sampling hooks are controlled
fixture boundaries; no controller is opened and no motor command leaves the
test. Every queue, input conversion/history and rumble cursor operation is real.

bits, transfer/disconnect samples, rumble loops/free reuse, exact twelve-tick
re-execution after Load, late malformed topology refusal without writes,
overlapping buffers, live-filter activity, callback/layout retirement and empty
rumble backing. Output suppression is host state and survives Load; only the
explicit final reconciliation issues four controlled device commands.

rollback timing acceptance. Caller snapshot buffers must be independent of all
aggregate companion backing, beyond this component's own alias checks.
