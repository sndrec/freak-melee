# Real common held-motion entry comparison

Original53 inputs are frozen in original53/ and complete function bodies in
original53.inc. original53_manifest.json pins source/function/Snapshot SHA256s.
Only symbol names differ in the compiled reference bodies; no branch or math
normalization. fixture.py validates originals then extracts complete candidate
open setup, consolidated entry and special-fall entry from the requested SDK.

The console links actual native_fighter_held_motion.c and the actual generation/
plink/depth registry. Definition lookup is an explicit controlled immutable
catalog. Motion change and animation-start are controlled boundaries; the motion
stub publishes ID and relevant SkipParasol flag effect, and captures exact
arguments plus pre-call previous-motion/timer/flag state. This is not a claim
that the entire engine transition, article animation request or physics executes.

Healthy pairs cover original auto blend0 vs consolidated0, original ignored-arg
startup blend10 vs consolidated10, and original fall vs actual modified fall.
Rows: Mario/raw Peach/custom, saved pointer absent/present, all8 common open
flag combinations,5 previous motions,3 old timers,3 common Float timer values.
Fractional common.x59C truncation through the original Int helper is checked;
startup's nominal Int argument remains ignored. Non-null partial definitions
with absent policy retain the exact raw pointer/kind predicate too.

Authored cases are separate callback contracts: owned ordinary state controls
369/370 mapping, actual previous/current values are observed before publication,
and proper package/common bounds apply. These are controlled typed C callbacks,
not a claim that an authored FMS callback was generated or stock source contained
that callback. Root owns compiler lowering and generated callback tests separately.

Safety cases execute retirement, recycling, kind and Definition changes inside
selector, motion and animation boundaries, invalid returned IDs, initially
retired/null-userdata source and depth64 exhaustion/nested dispatch balancing.
They do not execute the old unsafe cached continuation. Compare declared semantic
fields and exact float bits, never undefined struct padding or masked digests.

No core/default modifications, games or independent Peach acceptance.
