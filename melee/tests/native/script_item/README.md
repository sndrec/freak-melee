# Direct Item self binding fixture

From the repository root, use a fresh output directory on A::

```powershell
python tests/native/script_item/run.py --compiler A:/FreakMelee-test-archives/baseline72/compiler/clang.exe --output A:/FreakMelee-test-archives/script-item-review
```

Strict C11 warnings-as-errors, O2, disabled FP contraction and hidden process
creation. The receipt records source hashes, commands, stdout and exits. No
game launches.

Actual native fall/spin, lifetime, reflection/shield and four-surface bounce,
stage integration, pause/manual flags, Item sound and vector bodies are
extracted from the current checkout. Scene queries, moving-platform velocity,
audio device calls and dynamic-ECB observation are controlled. Unrelated engine
families explicitly reject execution in this standalone dependency view.

The actual production source->VM fixture runs fireball decrement/gravity and
Rook age/drift expressions, rather than native authored callbacks. Checks
also cover wide unsigned identities, holdable union tagging, flags, lifetime
rounding, reflection and sound handle/sentinel behavior.

State changes, spawn/removal, owner/creator interfaces, item scheduler hooks,
full scene behavior and aggregate rollback integration are outside this test.
## Collision-box extent regression

The Item-self property checks also cover all four `ecb.up/down/front/back`
fields through the real descriptor/property dispatch. Whole-Item comparisons
check that each write changes only the corresponding source-box field. Signed
zero, negative, infinity and NaN values retain the native assignment behavior;
wrong actor contexts and retired sources cannot write or publish a read result.
