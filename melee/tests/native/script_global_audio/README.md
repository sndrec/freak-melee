# Global audio boundary fixture

Run privately with a fresh directory on A:

```powershell
python tests/native/script_global_audio/run.py --compiler C:/Users/loser/scoop/apps/llvm/current/bin/clang.exe --output A:/FreakMelee-test-archives/script-global-audio-final
```

The runner extracts actual `lbAudioAx_800237A8` and `fn_80023750` bodies and
compares them with reference `d25ac9faa`. The AXDriver call is a silent sink that
records normalized arguments and supplies a signed native handle. The actual
interpreter compiler/catalog/Host dispatch, Prepare/Publish, Fighter and Article
actors, VM and fixed GObj pool execute.

Cases cover signed IDs, exact Int-only admission, ordinary doubling boundaries
and native clamps, high-ID fallback with ignored extreme arguments, returned
handle bits and `-1`, state/local/discarded results, argument evaluation once in
written order, two Article owners and the live destroyed-hook window. Invalid
physical source/storage contexts reject before the sink; bounded sink mutations
test result publication for Fighter and Article sources.

The receipt pins production, fixture, extracted source, compiler, headers and
relevant documentation/example inputs. This fixture opens no audio device and
does not execute the AX sound pool, rollback start journal, bank loading or mixer.
Injected mutations are controlled publication probes; actual audio contains no
authored callback in the audited call path. A completed native audio side effect
would remain after a guard failure.
