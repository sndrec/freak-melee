# Direct async attached effects

The fixture runs the real source parser, typed statements, bytecode and VM
through the direct feedback backend. Owned package/actor-view publication is
controlled; actual source guards, physical pool and callback registry are used.
It extracts unchanged native async spawn/process/flush/clear/init functions
from reference HEAD `7b077ac85`, the exact efSync1236 generator case, generator
attachment/ref_INC and class ancestry admission.

Queue allocation is a controlled eight-record reservation; the lower generator
resource/allocation leaf is controlled. Tests cover immediate/no-proc and link9,
deferred link8, native LIFO order, capacity failure, cancellation without spawn,
joint ref ownership, active-bit independence, full-width ABI rejection and
source/joint replacement across class admission/native publication. Injected
mutations are hazard evidence, not a claim native particle creation calls authored
helpers. Unrelated operations reject or abort.

The joint/scalar extension also exercises native mode 3 for effect IDs `0x490`
and `0x50c`, immediate/deferred delivery, signed-zero and finite scalar copying,
wrong-signature/nonfinite/type rejection, and thirteen source-retirement cases.
The actual source parser/bytecode/VM queues both a joint-only and scalar effect.
Those two scalar rendering leaves are controlled parameter receivers; the
queue, class admission and guards are production bodies. This is not rendered
Falcon/Ganondorf effect acceptance. The updated fixture passed 759 checks in
67 cases at `A:/FreakMelee-test-archives/script-async-scalar-ready-oct10/receipt.json`.

Typed frontend negatives reject floating effect IDs, wrong arity and Article
context. Native bodies and the exact sync case are checked against the prebatch
commit before compiling; receipt hashes cover landed source and generated inputs.

This is not rendered Peach, real actor/scheduler publication, full frozen/motion
scheduler ordering, particle command execution, or packed snapshot acceptance.
Production ObjAlloc can grow the native heap when empty; fixture reservation does
not establish production queue/generator capacity or allocation-free ticks.

Run with `run.py --compiler <MSVC-target clang.exe> --output <fresh A: directory>`.
Processes are hidden and all artifacts/receipts remain in that private directory.
